Full question

Retake exam · class-agnostic versus class-wise NMS

A detector produces the following predictions from one image:

BoxClassCoordinatesConfidence
ACar(30, 30, 90, 90)0.88
BCar(40, 40, 100, 100)0.80
CPerson(35, 35, 85, 85)0.72
DPerson(150, 150, 200, 200)0.60
ECar(160, 160, 210, 210)0.55

Use an NMS IoU threshold of \(0.50\). Suppress a box only when \(IoU>0.50\).

  1. Calculate \(IoU(A,B)\), \(IoU(A,C)\), and \(IoU(D,E)\).
  2. Apply class-agnostic NMS, where class labels are ignored.
  3. Apply class-wise NMS, where NMS is performed separately for Car and Person.
  4. Compare the results. Which box is protected by class-wise NMS, and why?

Complete solution

1. Required IoUs

A and B overlap over \(50\times50=2500\), and both have area 3600.

\[IoU(A,B)=\frac{{2500}}{{3600+3600-2500}}=\frac{{2500}}{{4700}}\approx0.532\]

C is inside A, so their intersection is 2500 and union is 3600.

\[IoU(A,C)=\frac{{2500}}{{3600}}\approx0.694\]

D and E overlap over \(40\times40=1600\). Each has area 2500.

\[IoU(D,E)=\frac{{1600}}{{2500+2500-1600}}=\frac{{1600}}{{3400}}\approx0.471\]
\[\boxed{{IoU(A,B)=0.532,\ IoU(A,C)=0.694,\ IoU(D,E)=0.471}}\]

2. Class-agnostic NMS

Order: \(A>B>C>D>E\). Keep A. Ignoring labels, A suppresses B and C because both IoUs exceed 0.50. Keep D. E remains because \(IoU(D,E)=0.471<0.50\).

\[\boxed{{\text{{Class-agnostic survivors}}=\{{A,D,E\}}}}\]

3. Class-wise NMS

Cars: A suppresses B because \(0.532>0.50\). E is far from A, so cars \(\{{A,E\}}\) survive.

Persons: C and D do not overlap, so both survive. Combine the two class results.

\[\boxed{{\text{{Class-wise survivors}}=\{{A,C,D,E\}}}}\]

4. Comparison

C is protected by class-wise NMS. Although C overlaps A strongly, C is a Person and A is a Car. Predictions from different classes do not suppress one another in class-wise NMS.

\[\boxed{{C\text{{ is saved because it belongs to a different class from A.}}}}\]
