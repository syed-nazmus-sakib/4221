Part I — Artificial Neural Networks

Master every common forward/backward variation until the shortcuts are automatic.

Objective

Master every common forward/backward variation. The goal is to recognize the output-layer shortcut, propagate the error with the correct activation derivative, and produce gradients with the correct dimensions without re-deriving backpropagation from scratch.

Stage A · One hidden layer

Practice all four base architectures:

\[ 2\to 2\to 1,\qquad 3\to 2\to 1,\qquad 2\to 3\to 1,\qquad 3\to 3\to 1. \]

Rotate through the following activation–loss combinations.

Case Hidden/output setup Loss Derivative to recognize immediately
1 ReLU → Sigmoid Binary cross-entropy \(\delta_o=\hat y-y\)
2 Sigmoid → Sigmoid Binary cross-entropy \(\delta_o=\hat y-y\), with \(\sigma'(z)=a(1-a)\) in the hidden layer
3 Tanh → Sigmoid Binary cross-entropy \(\delta_o=\hat y-y\), with \(\tanh'(z)=1-a^2\)
4 Sigmoid → Sigmoid Mean squared error \(\delta_o=(\hat y-y)\hat y(1-\hat y)\)

Give extra attention to Tanh hidden activation + Softmax output + categorical cross-entropy. It combines a simple output error, \(\delta_o=\hat{\boldsymbol y}-\boldsymbol y\), with the hidden derivative \(1-a^2\), and it matches the style of the recent in-course question.

Part II — Convolutional Neural Networks

Treat CNN preparation as a numerical unit. Couple every shape with its parameter count.

Objective

Master output-shape calculation + trainable-parameter counting together. In exam questions they are usually coupled. Then build speed in manual convolution, pooling, MACs, and efficient blocks.

Type 1 · Output shape

The CNN lab formula is

\[ \boxed{ H_{\mathrm{out}} = \left\lfloor \frac{H_{\mathrm{in}}-K+2P}{S} \right\rfloor+1 } \]

For rectangular kernels, compute height and width separately with \((K_h,P_h,S_h)\) and \((K_w,P_w,S_w)\). Output depth equals the number of filters.

Type 2 · Manual convolution

Use small \(4\times 4\), \(5\times 5\), and \(6\times 6\) matrices with:

  • \(2\times 2\) and \(3\times 3\) filters;
  • stride \(1\) and stride \(2\);
  • padding \(0\) and padding \(1\);
  • the full sequence \(\text{Convolution}\to\text{ReLU}\to\text{Pooling}\).

Type 3 · Pooling

Practice both max and average pooling with \(2\times 2,\ S=2\), \(2\times 2,\ S=1\), and unusual dimensions where the floor operation changes the output size.

Type 4 · Full-network parameter counting

For networks of the form

Input → Conv → Pool → Conv → Pool → Flatten → FC → FC

always calculate in this order: shape after every layer, then conv parameters, then flatten size, then FC parameters, then the total.

\[ \boxed{P_{\mathrm{conv}}=(K\times K\times C_{\mathrm{in}}+1)C_{\mathrm{out}}} \qquad \boxed{P_{\mathrm{FC}}=(n_{\mathrm{in}}+1)n_{\mathrm{out}}} \qquad \boxed{P_{\mathrm{pool}}=0} \]

The \(+1\) is the bias for each filter (or each FC neuron). Pooling has no trainable parameters.

The eight coupled drills below are the exam set. Tick them there, not as isolated shape questions.

Exam questions usually ask for both. Use the lab formulas, including the bias \(+1\). Attempt the prompt, then open the mark scheme.

Three traps — check every time
\[ \boxed{1.\ \text{Stride/padding affect spatial size, not parameter count}} \] \[ \boxed{2.\ \text{Number of filters determines output depth}} \] \[ \boxed{3.\ \text{Always calculate Flatten size before FC parameters}} \]

Type 1 · Intersection over Union

IoU measures the overlap between two bounding boxes relative to their combined area. A threshold of \(0.5\) is commonly used as a criterion for sufficiently overlapping localization.

\[ \boxed{ \operatorname{IoU}(A,B) =\frac{\text{intersection area}}{\text{union area}} } \qquad \boxed{A_U=A_A+A_B-A_I} \]

The six-step recipe

For

\[ A=(x_{1A},y_{1A},x_{2A},y_{2A}), \qquad B=(x_{1B},y_{1B},x_{2B},y_{2B}), \]

use the same sequence every time.

1

Find the intersection coordinates:

\[ x_L=\max(x_{1A},x_{1B}),\qquad y_T=\max(y_{1A},y_{1B}), \] \[ x_R=\min(x_{2A},x_{2B}),\qquad y_B=\min(y_{2A},y_{2B}). \]
2

Find the valid intersection width and height:

\[ \boxed{W_I=\max(0,x_R-x_L)}, \qquad \boxed{H_I=\max(0,y_B-y_T)}. \]
3

Calculate the intersection area:

\[A_I=W_I H_I.\]
4

Calculate the individual box areas:

\[A_A=(x_{2A}-x_{1A})(y_{2A}-y_{1A}),\] \[A_B=(x_{2B}-x_{1B})(y_{2B}-y_{1B}).\]
5

Calculate the union:

\[\boxed{A_U=A_A+A_B-A_I}.\]
6

Divide and compare with the required threshold:

\[\boxed{\operatorname{IoU}(A,B)=\frac{A_I}{A_U}}.\]
Most important coordinate rule
\[ \boxed{ \text{Intersection uses MAX for starting coordinates and MIN for ending coordinates.} } \]

The outer \(\max(0,\cdot)\) in \(W_I\) and \(H_I\) prevents a negative width or height when the boxes do not overlap.

IoU worked examples

Example 1 — \(A=(20,20,80,80)\), \(B=(40,30,100,90)\)

The intersection coordinates are

\[ \begin{aligned} x_L&=\max(20,40)=40, & y_T&=\max(20,30)=30,\\ x_R&=\min(80,100)=80, & y_B&=\min(80,90)=80. \end{aligned} \]

Thus, the overlapping rectangle runs from \((40,30)\) to \((80,80)\), giving

\[ W_I=80-40=40, \qquad H_I=80-30=50, \qquad \boxed{A_I=40\times 50=2000}. \]

The individual areas are

\[A_A=(80-20)(80-20)=60\times 60=3600,\] \[A_B=(100-40)(90-30)=60\times 60=3600.\]

Therefore,

\[A_U=3600+3600-2000=5200,\]

and

\[ \boxed{ \operatorname{IoU}(A,B)=\frac{2000}{5200}\approx 0.3846\approx 0.385 }. \]

Since \(0.385<0.5\), the boxes are not sufficiently overlapping at a threshold of \(0.5\). In same-class NMS with \(T=0.5\), the lower-confidence box would not be suppressed solely because of this IoU.

Problem 1 — Partial overlap

\[A=(10,10,50,50),\qquad B=(30,20,70,60).\]

The intersection is bounded by

\[x_L=30,\quad y_T=20,\quad x_R=50,\quad y_B=50,\]

so

\[W_I=20,\qquad H_I=30,\qquad \boxed{A_I=20\times 30=600}.\]

Both boxes have area \(40\times 40=1600\). Hence,

\[ A_U=1600+1600-600=2600, \qquad \boxed{\operatorname{IoU}=\frac{600}{2600}\approx 0.231}. \]

At a threshold of \(0.5\), there is not enough overlap.

Problem 2 — One box completely inside another

\[A=(20,20,100,100),\qquad B=(40,40,80,80).\]

Because \(B\) lies completely inside \(A\), its full area is the intersection:

\[ A_A=(100-20)^2=80^2=6400, \qquad A_B=(80-40)^2=40^2=1600, \] \[A_I=1600,\qquad A_U=6400+1600-1600=6400.\]

Therefore,

\[\boxed{\operatorname{IoU}=\frac{1600}{6400}=0.25}.\]

Key insight: even though \(B\) is entirely inside \(A\), the IoU is only \(0.25\) because the union is the whole larger box.

Problem 3 — Strong overlap

\[A=(20,20,80,80),\qquad B=(25,25,85,85).\]

The intersection runs from \((25,25)\) to \((80,80)\), so

\[W_I=H_I=55,\qquad \boxed{A_I=55^2=3025}.\]

Each box has area \(60\times 60=3600\). Therefore,

\[A_U=3600+3600-3025=4175,\] \[\boxed{\operatorname{IoU}=\frac{3025}{4175}\approx 0.725}.\]

Since \(0.725\geq 0.5\), this is strong overlap. In same-class NMS with \(T=0.5\), the lower-confidence prediction would normally be suppressed.

Problem 4 — No overlap

\[A=(10,10,40,40),\qquad B=(60,60,100,100).\]

Here,

\[x_L=\max(10,60)=60,\qquad x_R=\min(40,100)=40.\]

Because \(x_R<x_L\), there is no valid intersection width:

\[W_I=\max(0,40-60)=0,\qquad A_I=0.\]

Thus,

\[\boxed{\operatorname{IoU}=0}.\]

Exam shortcut: if the boxes clearly do not overlap, write \(\operatorname{IoU}=0\) immediately.

Problem 5 — Boxes touching at an edge

\[A=(10,10,50,50),\qquad B=(50,10,90,50).\]

The boxes meet at \(x=50\), but

\[x_L=\max(10,50)=50,\qquad x_R=\min(50,90)=50,\]

so

\[W_I=50-50=0.\]

Although the vertical overlap is \(50-10=40\), the intersection area is

\[A_I=0\times 40=0,\qquad \boxed{\operatorname{IoU}=0}.\]

Important trap: boxes that touch only along an edge or at one corner have zero intersection area and therefore zero IoU.

Bonus Problem 6 — Very different box sizes

\[A=(0,0,100,100),\qquad B=(25,25,75,75).\]

Box \(B\) is completely inside \(A\). The areas are

\[A_A=100\times 100=10000,\qquad A_B=50\times 50=2500.\]

Consequently,

\[A_I=2500,\qquad A_U=10000,\qquad \boxed{\operatorname{IoU}=\frac{2500}{10000}=0.25}.\]

Containment does not guarantee a high IoU: the relative box sizes still matter.

\[ \boxed{x_L=\max(x_{1A},x_{1B}),\quad x_R=\min(x_{2A},x_{2B})} \] \[ \boxed{y_T=\max(y_{1A},y_{1B}),\quad y_B=\min(y_{2A},y_{2B})} \] \[ \boxed{W_I=\max(0,x_R-x_L),\quad H_I=\max(0,y_B-y_T)} \]

Type 2 · Non-maximum suppression

Once IoU is automatic, NMS becomes a repeated selection-and-removal procedure. Unless stated otherwise, all boxes in the following examples predict the same class.

\[ \boxed{\text{The highest-confidence box survives.}} \] \[ \boxed{ \text{Remove a lower-confidence box when } \operatorname{IoU}\geq T_{\mathrm{NMS}}. } \]

Core NMS procedure

  1. Remove predictions below the confidence threshold, if one is given.
  2. Sort the remaining predictions from highest to lowest confidence.
  3. Select and keep the highest-confidence prediction.
  4. Compare its IoU with every lower-confidence prediction of the same class.
  5. Suppress predictions whose IoU is at least \(T_{\mathrm{NMS}}\).
  6. Select the next-highest surviving prediction and repeat.
The iterative rule
Do not compare every prediction only with the original highest-confidence box. After the first round, continue from the next-highest box that survived.

Problem 1 — Basic NMS

The same-class confidence scores are

\[A:0.92,\qquad B:0.85,\qquad C:0.70,\qquad D:0.60,\]

with

\[ \operatorname{IoU}(A,B)=0.72,\quad \operatorname{IoU}(A,C)=0.35,\quad \operatorname{IoU}(A,D)=0.10, \] \[ \operatorname{IoU}(C,D)=0.62, \qquad T_{\mathrm{NMS}}=0.5. \]
Round 1

\(A\) has the highest confidence, so keep \(A\). Then compare the remaining boxes with \(A\):

\[ \begin{array}{ccl} B: & 0.72\geq 0.5 & \Rightarrow \text{suppress }B,\\ C: & 0.35<0.5 & \Rightarrow \text{keep }C\text{ for now},\\ D: & 0.10<0.5 & \Rightarrow \text{keep }D\text{ for now}. \end{array} \]

The remaining candidates are \(C\) and \(D\).

Round 2

\(C\) has the larger remaining confidence, so keep \(C\). Since

\[\operatorname{IoU}(C,D)=0.62\geq 0.5,\]

\(D\) is suppressed. Therefore,

\[\boxed{\text{Final survivors}=\{A,C\}}.\]

Problem 2 — Change the NMS threshold

Use exactly the same predictions and IoUs, but set

\[T_{\mathrm{NMS}}=0.7.\]

Keep \(A\) first. Then

\[ \operatorname{IoU}(A,B)=0.72\geq 0.7 \quad\Rightarrow\quad B\text{ is suppressed}, \]

while

\[ \operatorname{IoU}(A,C)=0.35<0.7, \qquad \operatorname{IoU}(A,D)=0.10<0.7, \]

so \(C\) and \(D\) remain. Keep \(C\) next. Now

\[\operatorname{IoU}(C,D)=0.62<0.7,\]

so \(D\) is not suppressed. Hence,

\[\boxed{\text{Final survivors}=\{A,C,D\}}.\]

A higher threshold requires greater overlap before removal, so more overlapping predictions tend to survive.

Type 3 · Confidence threshold + NMS

The order of operations is essential:

\[ \boxed{ \text{confidence filtering first} \quad\Longrightarrow\quad \text{NMS second} } \]

Problem 3 — Confidence filtering followed by NMS

The predictions are

BoxConfidence

Step 1 — Confidence filtering. Remove every score below \(0.6\):

\[D:0.57\to\text{remove},\qquad E:0.42\to\text{remove}.\]

The candidates entering NMS are

\[\boxed{\{A,B,C\}}.\]

\[ \operatorname{IoU}(A,B)=0.66\geq 0.5 \quad\Rightarrow\quad B\text{ is suppressed}, \]

\[ \operatorname{IoU}(A,C)=0.20<0.5 \quad\Rightarrow\quad C\text{ survives}. \]

Keep \(C\). Therefore,

\[\boxed{\text{Final survivors}=\{A,C\}}.\]

This matches the in-course pattern exactly: low-confidence removal occurs before any IoU-based suppression.

Problem 4 — The second kept box suppresses another

Suppose

\[A:0.95,\qquad B:0.88,\qquad C:0.81,\qquad D:0.74,\]

and

\[ \operatorname{IoU}(A,B)=0.65,\quad \operatorname{IoU}(A,C)=0.30,\quad \operatorname{IoU}(A,D)=0.20, \] \[ \operatorname{IoU}(C,D)=0.75, \qquad T_{\mathrm{NMS}}=0.5. \]

First round: keep \(A\). Suppress \(B\) because \(0.65\geq 0.5\), while \(C\) and \(D\) survive because their IoUs with \(A\) are below the threshold.

Second round: \(C\) is now the highest-confidence survivor, so keep \(C\). Since

\[\operatorname{IoU}(C,D)=0.75\geq 0.5,\]

\(D\) is suppressed. Thus,

\[\boxed{\text{Final survivors}=\{A,C\}}.\]

Lesson: NMS must continue from the next-highest surviving prediction; it does not stop after comparisons with \(A\).

Problem 5 — Actual coordinates + NMS

Consider three same-class predictions:

\[ A=(10,10,50,50),\quad s_A=0.95, \] \[ B=(15,15,55,55),\quad s_B=0.85, \] \[ C=(70,70,110,110),\quad s_C=0.75, \qquad T_{\mathrm{NMS}}=0.5. \]

Boxes \(A\) and \(B\) each have area

\[40\times 40=1600.\]

Their intersection runs from \((15,15)\) to \((50,50)\), so

\[W_I=H_I=35,\qquad A_I=35^2=1225.\]

The union is

\[A_U=1600+1600-1225=1975,\]

giving

\[ \boxed{ \operatorname{IoU}(A,B)=\frac{1225}{1975}\approx 0.620 }. \]

Keep \(A\), then suppress \(B\) because \(0.620\geq 0.5\). Box \(C\) is spatially separate from \(A\), so

\[\operatorname{IoU}(A,C)=0\]

and \(C\) survives. Therefore,

\[\boxed{\text{Final survivors}=\{A,C\}}.\]

NMS exam recipe

Write this sequence before calculating.

  1. Confidence filter: \(s<T_{\mathrm{conf}}\Rightarrow\text{remove}\).
  2. Sort: arrange the remaining boxes from highest to lowest confidence.
  3. Pick: keep the highest-confidence box.
  4. Compare: if \(\operatorname{IoU}\geq T_{\mathrm{NMS}}\), suppress the lower-confidence box.
  5. Repeat: continue from the next-highest surviving box.
The two threshold effects
\[ \boxed{ T_{\mathrm{conf}}\uparrow \quad\Longrightarrow\quad \text{fewer boxes enter NMS} } \] \[ \boxed{ T_{\mathrm{NMS}}\uparrow \quad\Longrightarrow\quad \text{more overlapping boxes survive NMS} } \]

The confidence threshold controls the initial candidate set; the NMS threshold controls how much overlap is tolerated among those candidates.

Type 4 · TP, FP, and FN after NMS

After NMS produces the final prediction set, evaluation compares each prediction with the ground-truth objects of the same class. A common matching threshold is \(T_{\mathrm{eval}}=0.5\).

\[ \boxed{ \operatorname{IoU}(\text{prediction},\text{ground truth})\geq 0.5 \quad\Longrightarrow\quad \mathrm{TP} } \] \[ \boxed{ \operatorname{IoU}<0.5 \quad\Longrightarrow\quad \mathrm{FP} } \]
One-to-one matching rule

A ground-truth object can be matched only once. If two predictions both overlap the same ground truth sufficiently, process them in descending confidence order: the highest-confidence valid match becomes the true positive, while the duplicate becomes a false positive.

\[\boxed{\text{One ground truth cannot produce two true positives.}}\]

Problem 1 — One ground truth

Let

\[G=(20,20,80,80),\]

and suppose the following predictions remain after NMS:

\[A=(25,25,75,75),\quad s_A=0.90,\] \[B=(100,100,150,150),\quad s_B=0.70.\]

Use \(T_{\mathrm{eval}}=0.5\).

The ground-truth area is

\[A_G=60\times 60=3600.\]

Prediction \(A\) lies completely inside \(G\), and its area is

\[A_A=50\times 50=2500.\]

Therefore,

\[A_I=2500,\qquad A_U=3600+2500-2500=3600,\]

so

\[ \boxed{ \operatorname{IoU}(A,G)=\frac{2500}{3600}\approx 0.694 }. \]

Since \(0.694\geq 0.5\),

\[\boxed{A=\mathrm{TP}}.\]

Prediction \(B\) does not overlap \(G\), so

\[\operatorname{IoU}(B,G)=0\qquad\Longrightarrow\qquad\boxed{B=\mathrm{FP}}.\]

The final count is

\[\boxed{\mathrm{TP}=1,\qquad \mathrm{FP}=1}.\]

Problem 2 — Two predictions around one object

Consider one ground truth and two predictions:

\[G=(10,10,50,50),\] \[A=(12,12,48,48),\quad s_A=0.92,\qquad B=(14,14,46,46),\quad s_B=0.80.\]

Suppose both duplicates are still present. Since each lies inside \(G\),

\[ \operatorname{IoU}(A,G)=\frac{36^2}{40^2}=\frac{1296}{1600}=0.81, \] \[ \operatorname{IoU}(B,G)=\frac{32^2}{40^2}=\frac{1024}{1600}=0.64. \]

Both exceed \(0.5\), but both refer to the same object. Process the predictions by confidence: \(A\) matches \(G\) first, leaving no unmatched ground truth for \(B\). Thus,

\[\boxed{A=\mathrm{TP}},\qquad \boxed{B=\mathrm{FP}\text{ (duplicate)}}.\]

This is why duplicate detections reduce precision even when their localization is individually good.

Problem 3 — Two ground truths

Let

\[G_1=(10,10,50,50),\qquad G_2=(80,80,120,120),\]

with predictions

\[A=(12,12,48,48),\quad s_A=0.95,\] \[B=(78,78,122,122),\quad s_B=0.88,\] \[C=(30,70,60,100),\quad s_C=0.65.\]

Prediction \(A\) lies inside \(G_1\), giving

\[ \operatorname{IoU}(A,G_1)=\frac{36^2}{40^2}=\frac{1296}{1600}=0.81, \]

so \(A\) is a true positive matched to \(G_1\).

Prediction \(B\) has area \(44^2=1936\), while its intersection with \(G_2\) is \(40^2=1600\). Hence,

\[ \operatorname{IoU}(B,G_2) =\frac{1600}{1936+1600-1600} =\frac{1600}{1936} \approx 0.826, \]

so \(B\) is a true positive matched to \(G_2\).

Prediction \(C\) does not overlap either ground truth sufficiently, so it is a false positive. Therefore,

\[\boxed{A=\mathrm{TP},\qquad B=\mathrm{TP},\qquad C=\mathrm{FP}},\] \[\boxed{\mathrm{TP}=2,\qquad \mathrm{FP}=1}.\]

Problem 4 — A missed ground truth

Let

\[G_1=(10,10,50,50),\qquad G_2=(70,70,110,110),\]

and

\[A=(12,12,48,48),\quad s_A=0.93,\qquad B=(20,70,50,100),\quad s_B=0.72.\]

Prediction \(A\) matches \(G_1\), so

\[\boxed{A=\mathrm{TP}}.\]

Prediction \(B\) does not match \(G_2\) sufficiently, so

\[\boxed{B=\mathrm{FP}}.\]

Ground truth \(G_2\) has no valid prediction left to match it. Therefore,

\[\boxed{G_2=\mathrm{FN}},\]

and the final count is

\[\boxed{\mathrm{TP}=1,\qquad \mathrm{FP}=1,\qquad \mathrm{FN}=1}.\]

This is the first place a false negative appears: it is a real object that the detector failed to find.

Problem 5 — Precision and recall

Suppose evaluation gives

\[\mathrm{TP}=8,\qquad \mathrm{FP}=2,\qquad \mathrm{FN}=4.\]

Then

\[ \operatorname{Precision} =\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}} =\frac{8}{8+2} =\boxed{0.8}, \]

and

\[ \operatorname{Recall} =\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}} =\frac{8}{8+4} \approx\boxed{0.667}. \]
MetricInterpretation
PrecisionAmong the objects predicted by the model, how many predictions were correct?
RecallAmong the real objects in the image or dataset, how many did the model find?

Evaluation exam pattern

Apply predictions in confidence order.

  1. Sort the predictions from highest to lowest confidence.
  2. For each prediction, find the best unmatched ground truth of the same class.
  3. If the best IoU satisfies \(\operatorname{IoU}\geq T_{\mathrm{eval}}\), label the prediction \(\mathrm{TP}\) and mark that ground truth as matched.
  4. If no valid unmatched ground truth exists, label the prediction \(\mathrm{FP}\).
  5. After all predictions are processed, every unmatched ground truth is an \(\mathrm{FN}\).

Type 5 · Multiclass NMS

After low-confidence predictions are removed, divide the remaining predictions by class and run NMS independently within each group.

\[ \boxed{\text{Run NMS separately for each class.}} \] \[ \boxed{\text{Boxes of different classes do not suppress one another.}} \]

Thus, a car prediction should not suppress a pedestrian prediction, even when their boxes overlap heavily.

\[\boxed{\text{Pedestrian survivor}=C}.\]

Although \(C\) overlaps \(A\) strongly, the class labels differ. Therefore,

Suppose

\[A:\ \text{Car},\quad s_A=0.95,\qquad B:\ \text{Pedestrian},\quad s_B=0.90,\]

The IoU value \(0.90\) would trigger suppression only if the two predictions were competing within the same class. Here, one is a car and the other is a pedestrian, so their cross-class IoU is irrelevant to class-wise NMS.

Multiclass NMS exam recipe

Confidence Filtering → Split by Class → NMS Within Each Class → Merge Survivors
  1. Remove every prediction with \(s<T_{\mathrm{conf}}\).
  2. Group the remaining boxes by predicted class.
  3. Sort each class group from highest to lowest confidence.
  4. Run the complete iterative NMS procedure inside each group.
  5. Combine the surviving boxes from all classes.
Mistake to avoid
\[ \boxed{ \text{Never suppress a box merely because a different class overlaps it.} } \]

IoU-based suppression compares competing predictions for the same class; it does not remove valid detections of different object categories at the same location.

Type 6 · YOLO output dimensions and anchors

From the slides, YOLO assigns each object to the grid cell containing the object’s midpoint. With anchor boxes, the object is additionally assigned to the anchor having the highest IoU with its shape. The slide example uses a \(3\times 3\) grid, 2 anchors, and 3 classes, giving a target of \(3\times 3\times 2\times 8\).

1. YOLO output dimension

For each anchor, the prediction contains

\[[p_c,\, b_x,\, b_y,\, b_h,\, b_w,\, c_1,\ldots,c_C]\]

so each anchor predicts \(\boxed{5+C}\) numbers. With an \(S\times S\) grid, \(B\) anchors, and \(C\) classes, the output tensor is

\[ \boxed{S\times S\times B(5+C)} \]

Equivalently \(S\times S\times B\times(5+C)\). Both layouts store the same number of values.

2. Which grid cell gets the object?

YOLO does not assign the object according to where most of its area lies. It uses the bounding-box center.

\[ \boxed{\text{grid cell containing the object center}} \]

Example: a \(300\times 300\) image divided into a \(3\times 3\) grid. Each cell is \(100\times 100\). An object \((120,40,200,100)\) has center

\[ x_c=\frac{120+200}{2}=160,\qquad y_c=\frac{40+100}{2}=70. \]

\((160,70)\) lies in horizontal range \(100\to 200\) (column 2) and vertical range \(0\to 100\) (row 1), so the object is assigned to row 1, column 2 (one-based).

Always state whether row/column numbering is zero-based or one-based. \(\mathrm{col}=\lfloor x_c / \text{cell size}\rfloor\) is zero-based.

3. What do anchor boxes do?

Suppose a cell has two anchors: Anchor 1 tall and narrow, Anchor 2 short and wide. A pedestrian’s center in this cell usually matches the tall anchor; a car’s center in the same cell usually matches the wide anchor. The formal slide rule is

\[ \boxed{\text{Choose the anchor with the highest IoU with the ground-truth box}} \]

This helps one grid cell represent objects of different shapes.

The exam distinction
\[ \boxed{\text{Grid assignment uses CENTER}} \qquad \boxed{\text{Anchor assignment uses IoU}} \]

4. Two objects in the same grid cell

If a pedestrian center and a car center both fall in the same cell, and they match different anchors (tall vs wide), both can be represented. That is a motivation for anchor boxes.

If two pedestrians fall in the same cell and both prefer the same tall anchor, there is a conflict. That is a limitation of this simplified assignment scheme.

5. Understanding one YOLO label

Three classes: pedestrian, car, motorcycle. For one anchor the label has \(5+3=8\) entries:

\[\boxed{[p_c,\, b_x,\, b_y,\, b_h,\, b_w,\, c_1,\, c_2,\, c_3]}\]

For a car, \([c_1,c_2,c_3]=[0,1,0]\), so a positive anchor looks conceptually like

\[\boxed{[1,\, b_x,\, b_y,\, b_h,\, b_w,\, 0,\, 1,\, 0]}\]

If that anchor has no object, \(\boxed{p_c=0}\) and the remaining entries are not meaningful for that negative anchor in the simplified formulation shown in the slides.
