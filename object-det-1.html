Prerequisites — the only three ideas needed

iou · intersection · union · nms procedure

Before the problems, we only need three ideas:

\[ \text{Intersection width} = \max(0, \min(x_2^A,x_2^B)-\max(x_1^A,x_1^B)) \]

similarly for height, then

\[ A_{\text{intersection}} = w_I h_I \] \[ \boxed{\text{IoU}(A,B)=\frac{A_{\text{intersection}}}{A_A+A_B-A_{\text{intersection}}}} \]

For NMS: sort boxes by confidence → take the highest-confidence box → compare it with the remaining boxes → suppress those whose IoU is above the threshold → repeat.

Problem 1 — Previous-Year Final, 2025

Question 7, p.3 · theory: NMS + anchor boxes · 4 same-class boxes

This is Question 7 on page 3 of the previous final. It first asks some short theory about NMS and anchor boxes, then gives four same-class bounding boxes.

Given

Box\((x_1,y_1)\)\((x_2,y_2)\)Confidence
A(30, 30)(90, 90)0.88
B(40, 40)(100, 100)0.80
C(35, 35)(85, 85)0.72
D(150, 150)(200, 200)0.60

IoU threshold = 0.5, with no confidence filtering.

The numerical portion asks us to calculate IoU(A,B), IoU(A,C), IoU(A,D), run NMS, and then determine what happens if the IoU threshold is increased to 0.6. The same page also asks what problem NMS solves, how it works with multiple classes, and when anchor-box methods can perform poorly.

(i) IoU(A,B)

A: \((30,30) \rightarrow (90,90)\) so

\[ A_A = (90-30)(90-30) = 60 \times 60 = 3600. \]

B also has area

\[ A_B = (100-40)(100-40) = 3600. \]

The overlap begins at the larger top-left coordinate:

\[ (\max(30,40),\max(30,40)) = (40,40) \]

and ends at

\[ (\min(90,100),\min(90,100)) = (90,90). \]

Therefore,

\[ w_I = 90-40 = 50, \qquad h_I = 90-40 = 50 \]
\[ A_I = 50 \times 50 = 2500. \]

Union:

\[ A_U = 3600 + 3600 - 2500 = 4700. \]
\[ \boxed{\text{IoU}(A,B)=\frac{2500}{4700}\approx 0.532} \]

(ii) IoU(A,C)

C lies almost completely inside A.

\[ A_C = (85-35)(85-35) = 50 \times 50 = 2500. \]

Intersection is \((35,35) \rightarrow (85,85),\) so

\[ A_I = 50 \times 50 = 2500. \]

Thus

\[ A_U = 3600 + 2500 - 2500 = 3600 \]
\[ \boxed{\text{IoU}(A,C)=\frac{2500}{3600}\approx 0.694} \]

(iii) IoU(A,D)

A occupies roughly \(30\!-\!90\), while D starts at \(150\). There is no overlap.

\[ A_I = 0 \]
\[ \boxed{\text{IoU}(A,D)=0} \]

(iv) NMS with threshold 0.5

First sort by confidence:

\[ A(0.88) > B(0.80) > C(0.72) > D(0.60). \]

Take A first.

Compare A with B: \(0.532 > 0.5\) so B is suppressed.

Compare A with C: \(0.694 > 0.5\) so C is suppressed.

Compare A with D: \(0 < 0.5\) so D remains.

Nothing else overlaps D significantly.

\[ \boxed{\text{Final boxes}=\{A,D\}} \]

This is the basic NMS pattern we want to become automatic.

(v) Increase the IoU threshold to 0.6

This is an important conceptual variation. Again start with A.

For B: \(\text{IoU}(A,B)=0.532 < 0.6\) so B is no longer suppressed.

For C: \(\text{IoU}(A,C)=0.694 > 0.6\) so C is still suppressed.

D has no overlap.

\[ \boxed{\{A,B,D\}} \] survive.
Higher NMS IoU threshold → less aggressive suppression.
At threshold 0.5, B was considered “too similar” to A. At 0.6, an overlap of 0.532 is now acceptable.

For the short theory portions: NMS addresses the problem of multiple overlapping predictions for the same object. With multiple classes, NMS is normally performed separately for each class so a car box does not suppress a person box. The paper also asks when anchor-based detectors degrade; there is no supplied model solution for that theory item in the uploaded previous-year paper, but the standard answer is when predefined anchors poorly match the objects’ scales / aspect ratios, particularly for unusual or very small object geometries.

Problem 2 — Current In-Course Exam

same boxes A–D · threshold 0.5 · adds TP/FP + confidence filtering

This is extremely similar numerically, but the examiner changes the last two parts, which is useful for us. The four boxes are exactly A–D above, with threshold 0.5.

The question asks: (a) IoU(A,B) and IoU(A,C) · (b) ordinary NMS · (c) classify surviving boxes against a ground-truth box · (d) apply confidence filtering before NMS.

The first two answers are already known:

\[ \boxed{\text{IoU}(A,B)=0.532} \qquad \boxed{\text{IoU}(A,C)=0.694} \]

and NMS gives

\[ \boxed{\{A,D\}}. \]

These match the supplied model solution exactly.

(c) TP or FP against ground truth

Ground truth:

\[ G = (30,30,90,90). \]

The surviving predictions are A and D.

Box A

A is literally identical to G. Therefore,

\[ \text{IoU}(A,G) = 1. \]

Because \(1 \ge 0.5\),

\[ \boxed{A = \text{True Positive}} \]

Box D

D is far away from G.

\[ \text{IoU}(D,G) = 0. \]
\[ \boxed{D = \text{False Positive}} \]

This is exactly how the provided solution classifies them.

(d) Confidence threshold = 0.65 before NMS

Now there are two different thresholds. Do not confuse them:

confidence threshold = 0.65 NMS IoU threshold = 0.5

First apply confidence filtering:

\[ A:\; 0.88 \ge 0.65 \;\; \checkmark \qquad B:\; 0.80 \ge 0.65 \;\; \checkmark \] \[ C:\; 0.72 \ge 0.65 \;\; \checkmark \qquad D:\; 0.60 < 0.65 \;\; \times \]

So before NMS: \(\{A,B,C\}\) remain.

Now run NMS. A has highest confidence. \(IoU(A,B)=0.532 > 0.5\) therefore suppress B. \(IoU(A,C)=0.694 > 0.5\) therefore suppress C.

\[ \boxed{\text{Final survivor}=A} \]

which is again exactly the supplied model solution.

Confidence threshold removes boxes because their confidence is too low; NMS removes boxes because they overlap too much with a higher-confidence box.
That distinction is extremely exam-important.

Problem 3 — Retake Exam

multi-class · 5 boxes · class-agnostic vs multi-class NMS

This is the most interesting of the three because the examiner introduces multiple classes and adds a fifth box.

Given

BoxClassCoordinatesConfidence
Acar(30, 30) → (90, 90)0.88
Bcar(40, 40) → (100, 100)0.80
Cperson(35, 35) → (85, 85)0.72
Dperson(150, 150) → (200, 200)0.60
Ecar(150, 160) → (210, 220)0.55

The question asks for IoU(A,B), IoU(A,C), then compares class-agnostic NMS against multi-class NMS.

\[ \boxed{IoU(A,B)=0.532} \qquad \boxed{IoU(A,C)=0.694}. \]

(b) Class-agnostic NMS

Ignore the class labels completely.

Sort: \(A > B > C > D > E.\) Select A.

A vs B: \(0.532 > 0.5\) → suppress B.

A vs C: \(0.694 > 0.5\) → suppress C.

Notice something strange: A is a car and C is a person, but C still gets suppressed. Why? Because this NMS is class-agnostic.

A vs D and E: \(IoU = 0\) so both remain.

Next select D. We need IoU(D,E).

D: \((150,150) \rightarrow (200,200)\) · E: \((150,160) \rightarrow (210,220).\)

Intersection:

\[ x: 150 \rightarrow 200 \Rightarrow 50 \qquad y: 160 \rightarrow 200 \Rightarrow 40 \] \[ A_I = 50 \times 40 = 2000. \]

Union:

\[ 2500 + 3600 - 2000 = 4100. \]

Hence

\[ IoU(D,E) = \frac{2000}{4100} \approx 0.488. \]

Since \(0.488 < 0.5,\) E is kept.

\[ \boxed{\text{Class-agnostic survivors}=\{A,D,E\}} \]

which matches the retake model solution.

(c) Multi-class NMS

Now we separate the boxes by class.

Cars — \(A(0.88), B(0.80), E(0.55)\)

Select A. A vs B: \(0.532 > 0.5\) → B suppressed. A vs E: \(0 < 0.5\) → E kept.

\[ \boxed{\text{car survivors: } A, E} \]

Persons — \(C(0.72), D(0.60)\)

C and D do not overlap. Therefore both survive:

\[ \boxed{C, D} \]

Combine both classes:

\[ \boxed{\text{Multi-class survivors}=\{A,C,D,E\}} \]

The retake solution explicitly emphasizes that C is the box saved by multi-class NMS. Under class-agnostic NMS, car A suppressed person C because their IoU was 0.694. Under multi-class NMS, they belong to different classes and therefore cannot suppress each other.

What these three papers are actually testing

exam pattern · 5 operations

After doing all three, there are really only five operations we need to master:

  1. IoU calculation
  2. ordinary NMS
  3. changing the IoU threshold
  4. confidence filtering + NMS
  5. class-agnostic vs class-aware NMS, plus the very small TP/FP variation

And notice how clever the examiner has been: the first two IoUs are reused across all three papers. A/B gives \(0.532\), and A/C gives \(0.694\). The variation is mostly in what he asks you to do with those IoUs, not in making the arithmetic harder.

So these three exact questions already cover about 80–90% of the object-detection numerical pattern needed.

Next: 2–3 new object-detection problems in the same exact style, but with carefully changed numbers so you actually have to calculate rather than remember \(0.532\) and \(0.694\). Then object detection is finished, and we move straight to the exact LSTM questions from the previous final and in-course paper.
