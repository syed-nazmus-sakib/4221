Practice Problem 4 — Multi-Class NMS

One more proper multi-class NMS problem. Same structure as the retake: class-agnostic NMS can suppress overlapping boxes from different classes, whereas multi-class NMS only compares boxes within the same class.

Given

T_NMS = 0.50 · 6 predictions · Car / Person
BoxClass\((x_1,y_1)\)\((x_2,y_2)\)Conf.
ACar(10, 10)(70, 70)0.95
BCar(20, 20)(80, 80)0.88
CPerson(15, 15)(65, 65)0.84
DPerson(120, 120)(180, 180)0.78
ECar(130, 130)(190, 190)0.72
FPerson(125, 125)(175, 175)0.69
\[ \boxed{T_{\mathrm{NMS}} = 0.50} \]

(a) Compute \(IoU(A,B),\; IoU(A,C),\; IoU(D,E),\; IoU(D,F).\) Show intersection area, union area and final IoU.

(b) Apply class-agnostic NMS with threshold \(0.50\). Show every suppression decision.

(c) Apply multi-class NMS with threshold \(0.50\). Run NMS independently for Cars and Persons.

(d) Which predictions are saved by multi-class NMS compared with class-agnostic NMS? Explain.

(e) Start again from all six predictions. Apply a confidence threshold of \(0.75\) first and then perform multi-class NMS with IoU threshold \(0.50\). State the final detections.

Solution (a) — IoUs

1. \(IoU(A,B)\)

A: \((10,10)\rightarrow(70,70)\) · B: \((20,20)\rightarrow(80,80)\) · Each area \(60\times 60 = 3600.\)

Intersection: \((20,20)\rightarrow(70,70)\) so \(A_I = 50\times 50 = 2500.\)

\[ A_U = 3600+3600-2500 = 4700. \]
\[ \boxed{IoU(A,B)=\frac{2500}{4700}\approx 0.532} \]

They are also both Cars.

2. \(IoU(A,C)\)

C: \((15,15)\rightarrow(65,65)\) · Area \(50\times 50 = 2500.\) C lies completely inside A. Therefore \(A_I = 2500.\)

\[ A_U = 3600+2500-2500 = 3600. \]
\[ \boxed{IoU(A,C)=\frac{2500}{3600}\approx 0.694} \]

Notice \(0.694 > 0.5\) but A = Car, C = Person. Keep that in mind.

3. \(IoU(D,E)\)

D: \((120,120)\rightarrow(180,180)\) · E: \((130,130)\rightarrow(190,190)\) · Both area \(3600.\)

Intersection: \((130,130)\rightarrow(180,180)\) so \(A_I = 50\times 50 = 2500.\)

\[ A_U = 3600+3600-2500 = 4700. \]
\[ \boxed{IoU(D,E)\approx 0.532} \]

But D = Person, E = Car.

4. \(IoU(D,F)\)

F: \((125,125)\rightarrow(175,175)\) · Area \(2500.\) F lies completely inside D. So \(A_I = 2500\) and \(A_U = 3600+2500-2500 = 3600.\)

\[ \boxed{IoU(D,F)=\frac{2500}{3600}\approx 0.694} \]

D and F are both Persons.

Solution (b) — Class-Agnostic NMS

Ignore all class labels. Confidence ordering:

\[ A(.95) > B(.88) > C(.84) > D(.78) > E(.72) > F(.69) \]

Step 1: Select A

Keep A. A vs B: \(0.532 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

A vs C: \(0.694 > 0.50\)

\[ \boxed{\text{Suppress C}} \]

Even though C is a Person, class-agnostic NMS does not care. A has no meaningful overlap with D, E or F. Keep them. Remaining: \(D, E, F.\)

Step 2: Select D

D has confidence \(0.78\), so select D. D vs E: \(IoU(D,E) = 0.532 > 0.50\)

\[ \boxed{\text{Suppress E}} \]

Again, D is Person and E is Car. Doesn't matter here.

D vs F: \(IoU(D,F) = 0.694 > 0.50\)

\[ \boxed{\text{Suppress F}} \]

Nothing remains.

\[ \boxed{\text{Class-agnostic survivors}=\{A,D\}} \]

Solution (c) — Multi-Class NMS

Now class labels matter. We separate the predictions.

Cars — \(A(.95),\; B(.88),\; E(.72)\)

Select A. Compare A with B: \(IoU(A,B) = 0.532 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

Compare A with E. Far apart: \(IoU(A,E) = 0.\)

\[ \boxed{\text{Keep E}} \]
\[ \boxed{\{A,E\}} \]

Persons — \(C(.84),\; D(.78),\; F(.69)\)

Select C. C is far away from D and F. Therefore \(IoU(C,D) = 0\) and \(IoU(C,F) = 0.\) Keep both. Remaining: \(D, F.\)

Select D. Now \(IoU(D,F) = 0.694 > 0.50.\) Because D and F are both Persons:

\[ \boxed{\text{Suppress F}} \]
\[ \boxed{\{C,D\}} \]

Combine both classes:

\[ \boxed{\text{Multi-class survivors}=\{A,C,D,E\}} \]

Precisely the logic used in the retake solution: run NMS independently inside each class, then combine the survivors.

Solution (d) — Which boxes did multi-class NMS save?

Class-agnostic gave \(\boxed{\{A,D\}}\). Multi-class gave \(\boxed{\{A,C,D,E\}}\). Therefore multi-class NMS saved:

\[ \boxed{C\text{ and }E} \]

Why was C saved?

A and C overlap heavily: \(IoU(A,C) = 0.694.\) Class-agnostic: \(0.694 > 0.5\) so A suppresses C. But in multi-class NMS \(A = \text{Car},\; C = \text{Person}.\) They are never compared. Hence C survives.

Why was E saved?

Similarly \(IoU(D,E) = 0.532 > 0.5.\) Class-agnostic: \(D \rightarrow \text{suppresses E}.\) But \(D = \text{Person},\; E = \text{Car}.\) Multi-class NMS does not compare them. Hence E survives.

Key rule: \[ \boxed{\text{High IoU alone is NOT enough for suppression in multi-class NMS.}} \] You need: \[ \boxed{\text{same class AND IoU above threshold}} \]

Solution (e) — Confidence filtering + Multi-Class NMS

\[ T_{\mathrm{conf}} = 0.75. \]

Check each prediction: \(A = 0.95\;\checkmark\) · \(B = 0.88\;\checkmark\) · \(C = 0.84\;\checkmark\) · \(D = 0.78\;\checkmark\) · \(E = 0.72\;\times\) · \(F = 0.69\;\times\)

\[ \boxed{\{A,B,C,D\}} \]

Now multi-class NMS.

Cars — \(A,B\)

\(IoU(A,B) = 0.532 > 0.50.\) A has greater confidence \(0.95 > 0.88.\) Therefore A suppresses B. Car survivor: \(\boxed{A}\)

Persons — \(C,D\)

They are spatially separated: \(IoU(C,D) = 0.\) Therefore both survive. Person survivors: \(\boxed{C,D}\)

\[ \boxed{\{A,C,D\}} \]

Quick check

That table is basically the whole concept of multi-class NMS.
