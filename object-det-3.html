Same versatile structure because it matches the exact exam family: IoU calculation, step-by-step NMS, TP/FP classification, confidence filtering before NMS, and changing the IoU threshold. Those are all directly represented in the in-course question / solution pattern.

Given

same object class · NMS IoU threshold 0.50 initially

A detector predicts five bounding boxes for the same object class:

Box\((x_1,y_1)\)\((x_2,y_2)\)Confidence
A(10, 10)(70, 70)0.94
B(20, 20)(80, 80)0.86
C(5, 5)(60, 60)0.79
D(65, 65)(115, 115)0.72
E(70, 70)(120, 120)0.66

Initially, use an NMS IoU threshold of 0.50.

Questions

(a) Compute: \[ IoU(A,B), \qquad IoU(A,C), \qquad IoU(D,E) \] For each one, show: intersection width and height, intersection area, union area, final IoU.

(b) Apply standard NMS with threshold \[ T_{NMS}=0.50. \] Show every suppression decision step-by-step and state the final surviving boxes.

(c) Suppose the ground-truth box is \[ G=(12,12,72,72). \] Using only the boxes that survived part (b), classify each surviving prediction as \[ \text{True Positive if IoU}\ge 0.5 \] or False Positive otherwise.

(d) Start again from all five original boxes. Before NMS, apply a confidence threshold of 0.75. Then apply NMS with IoU threshold \(0.50\). State: 1. which boxes survive confidence filtering; 2. which boxes survive the final NMS.

(e) Start again from all five original boxes, with no confidence filtering. Increase the NMS threshold from \[ 0.50 \rightarrow 0.65. \] Apply NMS again and state the final surviving boxes.

(f) Briefly explain why increasing the NMS threshold from \(0.50\) to \(0.65\) generally causes more boxes to survive.

Try it yourself first. Then compare.

Solution (a) — IoUs

1. \(IoU(A,B)\)

Box A: \((10,10) \rightarrow (70,70)\)

\[ A_A = (70-10)(70-10) = 60 \times 60 = 3600 \]

Box B: \((20,20) \rightarrow (80,80)\)

\[ A_B = 60 \times 60 = 3600 \]

Intersection coordinates:

\[ (\max(10,20),\max(10,20)) = (20,20) \] \[ \text{to} \] \[ (\min(70,80),\min(70,80)) = (70,70) \]

Therefore:

\[ W_I = 70-20 = 50 \] \[ H_I = 70-20 = 50 \] \[ A_I = 50 \times 50 = 2500 \]

Union:

\[ A_U = 3600 + 3600 - 2500 = 4700 \]
\[ \boxed{IoU(A,B)=\frac{2500}{4700}\approx 0.532} \]

Since \(0.532 > 0.50,\) A can suppress B under NMS threshold 0.5.

2. \(IoU(A,C)\)

C: \((5,5) \rightarrow (60,60)\)

\[ A_C = (60-5)^2 = 55^2 = 3025 \]

Intersection A–C: \((10,10) \rightarrow (60,60)\) so

\[ W_I = 50, \qquad H_I = 50 \] \[ A_I = 2500 \]

Union:

\[ A_U = 3600 + 3025 - 2500 \] \[ = 4125 \]
\[ \boxed{IoU(A,C)=\frac{2500}{4125}\approx 0.606} \]

Again, \(0.606 > 0.50.\) So A can suppress C.

3. \(IoU(D,E)\)

D: \((65,65) \rightarrow (115,115)\)

\[ A_D = 50 \times 50 = 2500 \]

E: \((70,70) \rightarrow (120,120)\)

\[ A_E = 2500 \]

Intersection: \((70,70) \rightarrow (115,115)\)

\[ W_I = 45, \qquad H_I = 45 \] \[ A_I = 45 \times 45 = 2025 \]

Union:

\[ A_U = 2500 + 2500 - 2025 \] \[ = 2975 \]
\[ \boxed{IoU(D,E)=\frac{2025}{2975}\approx 0.681} \]

Solution (b) — NMS with threshold 0.50

sort → select → suppress → repeat · two-stage suppression

Sort by confidence:

\[ A(0.94) > B(0.86) > C(0.79) > D(0.72) > E(0.66) \]

Step 1: Select A

Keep A.

Compare with B: \(IoU(A,B) = 0.532 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

Compare with C: \(IoU(A,C) = 0.606 > 0.50\)

\[ \boxed{\text{Suppress C}} \]

Compare with D. A ends at \((70,70)\), while D starts at \((65,65)\). There is only a tiny overlap: \((65,65) \rightarrow (70,70)\). Intersection \(5 \times 5 = 25\) which gives a very small IoU, far below 0.5.

\[ \boxed{\text{Keep D}} \]

A and E only touch at the point \((70,70)\), giving zero intersection area.

\[ \boxed{\text{Keep E}} \]

After A: \(\{D, E\}\) remain.

Step 2: Select D

D has higher confidence than E. We already calculated: \(IoU(D,E) = 0.681.\) Since \(0.681 > 0.50\),

\[ \boxed{\text{Suppress E}} \]
\[ \boxed{\text{Final survivors}=\{A,D\}} \]

This is a particularly useful NMS example because suppression happens in two stages: \(A \rightarrow B,C\) then \(D \rightarrow E.\)

Solution (c) — TP / FP

G = (12,12,72,72) · survivors A, D

Ground truth:

\[ G = (12,12,72,72) \]

The NMS survivors are: \(A, D.\)

A vs G

Both have area \(60 \times 60 = 3600.\)

Intersection: \((12,12) \rightarrow (70,70)\) so

\[ W_I = 58, \qquad H_I = 58 \] \[ A_I = 58^2 = 3364. \]

Union:

\[ A_U = 3600 + 3600 - 3364 \] \[ = 3836. \]

Thus

\[ IoU(A,G) = \frac{3364}{3836} \approx 0.877. \]

Since \(0.877 \ge 0.5\),

\[ \boxed{A = \text{True Positive}} \]

D vs G

There is only a tiny overlap between them. G ends at \((72,72)\), while D starts at \((65,65)\). Intersection: \((65,65) \rightarrow (72,72)\). Area: \(7 \times 7 = 49.\) This produces an IoU far below 0.5.

\[ \boxed{D = \text{False Positive}} \]
\[ \boxed{A = TP, \qquad D = FP} \]

Solution (d) — Confidence threshold = 0.75

confidence first → NMS second

First apply:

\[ T_{\text{conf}} = 0.75. \]

A: \(0.94 \ge 0.75\) — keep.   B: \(0.86 \ge 0.75\) — keep.   C: \(0.79 \ge 0.75\) — keep.

D: \(0.72 < 0.75\) — discard.   E: \(0.66 < 0.75\) — discard.

Therefore after confidence filtering:

\[ \boxed{\{A,B,C\}} \]

Now NMS with threshold 0.50. Select A. \(IoU(A,B) = 0.532 > 0.50\) — suppress B. \(IoU(A,C) = 0.606 > 0.50\) — suppress C.

\[ \boxed{\text{Final survivor}=A} \]
Notice again: \[ \boxed{\text{Confidence filter first}\rightarrow\text{NMS second}} \]

Solution (e) — Increase NMS threshold to 0.65

all five boxes · no confidence filtering · T = 0.65

Now use all five original boxes. No confidence filtering.

\[ T_{NMS} = 0.65. \]

Select A.

A vs B

\(0.532 < 0.65\) so B survives.

A vs C

\(0.606 < 0.65\) so C survives.

A vs D

tiny IoU \(< 0.65\) so D survives.

A vs E

\(IoU = 0\) so E survives.

Thus A suppresses nobody. Next select B. B does not have sufficiently large overlap with C, D, or E to cross 0.65, so they remain. Next select C. Again, no suppression.

Next select D. Now: \(IoU(D,E) = 0.681.\) Since \(0.681 > 0.65,\) D suppresses E.

\[ \boxed{\text{Final survivors}=\{A,B,C,D\}} \]

Compare:

\[ T = 0.50 \Rightarrow \{A,D\} \] \[ \text{whereas} \] \[ T = 0.65 \Rightarrow \{A,B,C,D\}. \]

Solution (f) — Why?

A box is suppressed only when

\[ IoU > T_{NMS}. \]

If we increase the threshold, it becomes harder for two boxes to satisfy that suppression condition.

For example: \(IoU(A,B) = 0.532.\) At threshold 0.50: \(0.532 > 0.50\) so B is suppressed. At threshold 0.65: \(0.532 < 0.65\) so B survives.

\[ \boxed{\text{Higher NMS threshold}\Rightarrow \text{less aggressive NMS}\Rightarrow \text{more boxes survive}} \]

This one gives you almost the entire same-class object-detection exam family again, but the nice extra twist is the second cluster \(D,E\), which forces you to continue NMS after processing A instead of stopping mentally after the first box.
