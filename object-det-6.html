Ground-truth objects:

\[ T_{\text{NMS}} = 0.50 \qquad T_{\text{IoU,GT}} = 0.50. \]

(a) Compute \(IoU(A,B),\; IoU(C,D).\)

(b) Apply multi-class NMS.

(c) Match the surviving predictions to the ground-truth objects. A prediction is a TP only if: 1. its class matches the GT, 2. its IoU with that GT is at least \(0.5,\) 3. each ground-truth object can be matched to only one prediction. Classify every survivor as TP or FP.

(d) Compute precision: \[ \text{Precision} = \frac{TP}{TP+FP}. \]

Solution (a) — IoUs

A vs B

Both are \(60\times 60\): \(A_A = A_B = 3600.\) Intersection: \((28,28)\rightarrow(80,80)\) so \(w_I = 52,\; h_I = 52\), \(A_I = 52\times 52 = 2704.\)

\[ A_U = 3600+3600-2704 = 4496. \]
\[ IoU(A,B) = \frac{2704}{4496} \approx 0.601. \]
\[ \boxed{IoU(A,B)\approx 0.601} \]

C vs D

The geometry is identical: C \((120,120)\rightarrow(180,180)\), D \((128,128)\rightarrow(188,188).\) Again \(A_I = 52\times 52 = 2704\) and \(A_U = 4496.\)

\[ \boxed{IoU(C,D)\approx 0.601} \]

Solution (b) — Multi-Class NMS

We process classes separately.

Cars — \(A(0.94),\; B(0.87),\; E(0.76)\)

Select A. A vs B: \(0.601 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

A vs E: A ends at \(x = 80\), while E begins at \(x = 130.\) No overlap: \(IoU(A,E) = 0.\) So E remains.

\[ \boxed{\{A,E\}} \]

Persons — \(C(0.91),\; D(0.83),\; F(0.63)\)

Select C. C vs D: \(0.601 > 0.50\)

\[ \boxed{\text{Suppress D}} \]

C vs F: spatially separate. \(IoU(C,F) = 0\) so F remains.

\[ \boxed{\{C,F\}} \]
\[ \boxed{\text{NMS survivors}=\{A,C,E,F\}} \]

Solution (c) — Match predictions to ground truth

one-to-one matching · class must match · IoU ≥ 0.5

Ground truths: \(G_1 = \text{Car}\), \(G_2 = \text{Person}\). Predictions surviving NMS: \(A,\; C,\; E,\; F.\)

Prediction A

A: \(\text{Car }(20,20,80,80)\) is identical to \(G_1\): \(\text{Car }(20,20,80,80).\)

\[ IoU(A,G_1) = 1. \]

Class matches and \(1 \ge 0.5.\)

\[ \boxed{A = TP} \]

Now \(G_1\) is considered matched.

Prediction C

C: \(\text{Person }(120,120,180,180)\) is exactly \(G_2.\) Thus \(IoU(C,G_2) = 1.\)

\[ \boxed{C = TP} \]

Now \(G_2\) is also matched.

Prediction E

E: \(\text{Car }(130,20,180,70)\). Only one Car ground truth, \(G_1\), and E does not overlap it. \(IoU(E,G_1) = 0.\)

\[ \boxed{E = FP} \]

Prediction F

F: \(\text{Person }(10,120,60,170)\). The Person GT is \(G_2 = (120,120,180,180).\) They do not overlap. \(IoU(F,G_2) = 0.\)

\[ \boxed{F = FP} \]

Why the one-to-one rule matters

Suppose B had somehow survived NMS too. B overlaps \(G_1\) strongly. You might initially think: A matches the Car GT and B also matches the Car GT, so both are TP. No. A single physical object should not give you two correct detections. Once A has matched \(G_1\),

\[ \boxed{G_1\text{ cannot be matched again}} \]

so another duplicate detection of the same ground-truth object becomes an FP. This is actually one reason NMS is useful in the first place.

Solution (d) — Precision

We have \(TP = 2,\; FP = 2.\)

\[ \text{Precision} = \frac{TP}{TP+FP} \] \[ = \frac{2}{2+2} \] \[ = \frac12 \]
\[ \boxed{\text{Precision} = 0.50 = 50\%} \]

And the three thresholds should never get mixed up:

\(\boxed{\text{Confidence threshold}}\) → Is the prediction confident enough to consider?
\(\boxed{\text{NMS IoU threshold}}\) → Is this prediction too similar to another prediction?
\(\boxed{\text{GT IoU threshold}}\) → Is this prediction accurate enough to count as a correct detection?
