1. Why activation functions exist

A neuron first computes \(z=w^{T}x+b\), then applies \(a=f(z)\). The second step is where all the power comes from.

Without a nonlinear activation, stacking layers achieves nothing. Two linear layers compose to

\[ W_2(W_1x+b_1)+b_2 = \underbrace{W_2W_1}_{W'}x + \underbrace{W_2b_1+b_2}_{b'} = W'x+b' \]
\[ \boxed{ \text{A stack of linear layers is just one linear layer.} } \]

No matter how deep the network, it could only ever learn a linear mapping. Nonlinear activations are what let a network represent complex nonlinear relationships — and what make depth meaningful.

         w, b              f(·)
   x ──► z = wᵀx + b ──► a = f(z) ──► next layer
         │                 │
     linear part      the nonlinearity
    (does the work)   (makes depth matter)

2. Sigmoid

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

Range

\[ \boxed{ 0<\sigma(z)<1 } \]

so it naturally behaves like a probability. Key values:

\[ \sigma(0)=0.5, \qquad z\to+\infty \Rightarrow \sigma(z)\to1, \qquad z\to-\infty \Rightarrow \sigma(z)\to0 \]

Derivative

\[ \boxed{ \sigma'(z)=\sigma(z)\big(1-\sigma(z)\big) } \]

Its maximum value is only \(\boxed{0.25}\), reached at \(z=0\).

   σ(z)                          σ'(z)
  1 ┤        ╭────────         0.25┤    ╭╮
    │      ╭─╯                     │   ╱  ╲
0.5 ┤────╭─╯──────────         0.1 ┤  ╱    ╲
    │  ╭─╯                         │ ╱      ╲
  0 ┤──╯                         0 ┤╯        ╰────
    └──────┼──────►                └────┼────────►
    -6     0      6                -6   0        6
                                   flat where σ saturates

Main use

\[ \boxed{ \text{One output neuron + Sigmoid} \;\Rightarrow\; \text{binary classification} } \]

Disadvantage

For large \(|z|\), sigmoid saturates and its derivative becomes almost zero, causing vanishing gradients. Even at its very best it shrinks the gradient by a factor of 4.

3. Tanh

\[ \boxed{ \tanh(z)=\frac{e^{z}-e^{-z}}{e^{z}+e^{-z}} } \]

Range

\[ \boxed{ -1<\tanh(z)<1 }, \qquad \tanh(0)=0 \]

Unlike sigmoid, it is zero-centred.

Derivative

\[ \boxed{ \tanh'(z)=1-\tanh^{2}(z) } \]

with a maximum of \(1\) at \(z=0\) — four times better than sigmoid's best case.

Advantage over sigmoid

Its outputs contain both positive and negative values centred around zero, which generally makes optimisation better behaved: activations passed forward do not all share the same sign.

Disadvantage

Tanh still saturates: \(z\to\pm\infty \Rightarrow \tanh(z)\to\pm1\), so its gradient can also vanish. It is milder than sigmoid, not immune.

4. ReLU

Rectified Linear Unit:

\[ \boxed{ ReLU(z)=\max(0,z) } \qquad\text{or}\qquad ReLU(z)=\begin{cases} z, & z>0 \\ 0, & z\le 0 \end{cases} \]

Range and derivative

\[ \boxed{ [0,\infty) } \qquad ReLU'(z)=\begin{cases} 1, & z>0 \\ 0, & z<0 \end{cases} \]

The derivative at \(z=0\) is mathematically undefined; implementations pick a convention (usually 0).

   ReLU(z)                       ReLU'(z)
    │        ╱                   1 ┤      ┌────────
    │      ╱                       │      │
    │    ╱                         │      │
  0 ┤────────────                0 ┤──────┘
    └────┼───────►                 └──────┼───────►
        0                                0
   flat then linear              0 then exactly 1 — no shrinking

Advantages

  • Very simple to compute — a comparison, not an exponential.
  • Does not saturate for positive inputs.
  • Derivative is exactly \(1\) where active, so gradients pass through undiminished — this is what largely solved the vanishing-gradient problem.
  • Produces sparse representations, since roughly half the units output zero.

Main disadvantage — the dying ReLU

If a neuron continually receives \(z<0\), then

\[ ReLU(z)=0 \qquad\text{and}\qquad ReLU'(z)=0 \]

so it contributes nothing forward and receives no gradient backward. It may stop learning permanently.

Seen concretely in ANN-6 and ANN-8, where a dead unit leaves an entire column of \(\nabla W\) at zero and those weights never move.

5. Leaky ReLU

Leaky ReLU modifies only the negative side:

\[ \boxed{ f(z)=\begin{cases} z, & z>0 \\ 0.01z, & z\le 0 \end{cases} } \]

Instead of completely killing negative inputs, it gives them a small slope. Therefore

\[ z<0 \;\Rightarrow\; f'(z)=0.01 \quad\text{instead of }0 \]
\[ \boxed{ \text{Purpose: reduce the dying-ReLU problem} } \]

A small gradient can still flow when \(z<0\), so a unit that drifts negative retains a route back.

   ReLU                          Leaky ReLU
    │        ╱                    │        ╱
    │      ╱                      │      ╱
  0 ┤────────                   0 ┤────╱
    │                             │  ╱  ← small slope 0.01, not flat
    └────┼───────►                └──┼───────►
        0                            0
   dead below zero            still alive below zero

The trade-off is one extra hyperparameter: the negative slope. \(0.01\) is the usual default.

6. Softmax

Softmax differs from everything above: it takes an entire vector of logits \(z_1,z_2,\ldots,z_C\) and converts them into class probabilities.

\[ \boxed{ \hat y_i=\frac{e^{z_i}}{\sum_{j=1}^{C}e^{z_j}} } \]

with \(0<\hat y_i<1\) and, crucially,

\[ \boxed{ \sum_i \hat y_i = 1 } \]

Main use

\[ \boxed{ \text{Mutually exclusive multiclass classification} } \]

Example

Take \(z=[2,\ 1,\ 0]\):

\(z_i\)\(e^{z_i}\)\(\hat y_i\)
27.3890.665

sum11.1071.000

The classes compete with one another, because the shared denominator forces the probabilities to sum to 1. Raising one necessarily lowers the others.

Softmax is unchanged if you subtract the same constant from every logit, so \(c=\max_j z_j\) is often subtracted first to keep the exponentials small. Same answer, easier arithmetic.

7. Linear activation

For regression, the output layer often uses no activation at all:

\[ \boxed{ f(z)=z }, \qquad -\infty

There is no restriction on the output, which is what a continuous target needs — temperature, price, force, position.

This is why the regression problems use the pattern

\[ \boxed{ \text{ReLU / tanh hidden layer} \;\rightarrow\; \text{Linear output} } \]

A sigmoid output would cap the prediction at 1, and a ReLU output would forbid negative predictions. See ANN-5 through ANN-8 — and note that a linear activation in a hidden layer is useless, for the reason given in section 1.

8. Sigmoid vs Softmax — the key exam distinction

Binary classification

One sigmoid output: \(\boxed{\hat y=\sigma(z)}\) — for example \(P(\text{cat})=0.82\), with \(P(\text{not cat})=0.18\) implied.

Multiclass classification

Softmax over all classes: \(\boxed{[P_1,P_2,P_3]}\) with \(\sum P=1\) — for example \([0.1,\,0.7,\,0.2]\).

Multi-label classification

If several labels can be true at the same time, use independent sigmoids, not softmax. An image may contain both a person and a car:

\[ P(\text{person})=0.9, \qquad P(\text{car})=0.8 \]

These do not need to sum to 1 — and softmax would wrongly force them to compete.

TaskOutput layerDo probabilities sum to 1?
Binary1 neuron + sigmoidn/a (two outcomes implied)
Multiclass, mutually exclusive\(C\) neurons + softmaxyes
Multi-label, independent\(C\) neurons + \(C\) sigmoidsno

The deciding question is simply: can two labels be true at once? If yes, sigmoid. If no, softmax.

10. Likely exam questions

Q1. Why are activation functions necessary in neural networks?

Activation functions introduce nonlinearity. Without them, multiple linear layers collapse into a single linear transformation:

\[ W_2(W_1x+b_1)+b_2 = W'x+b' \]

Regardless of depth, the network could only learn linear mappings. Nonlinear activations allow it to represent complex nonlinear relationships.

Q2. Compare Sigmoid and Tanh.

Both are smooth nonlinear functions and both can suffer vanishing gradients through saturation. Sigmoid outputs lie in \((0,1)\) while tanh outputs lie in \((-1,1)\). Tanh is zero-centred, which is generally preferable for hidden representations; sigmoid is especially useful for binary probability outputs. Tanh's derivative peaks at \(1\) against sigmoid's \(0.25\), so tanh is the milder of the two.

Q3. Why is ReLU commonly preferred over Sigmoid in hidden layers?

For positive inputs \(ReLU'(z)=1\), so gradients do not shrink through activation saturation. ReLU is also computationally trivial and produces sparse representations. Sigmoid saturates for large positive and negative inputs, driving its derivative toward zero and increasing the risk of vanishing gradients.

Q4. What is the dying-ReLU problem and how does Leaky ReLU address it?

If a ReLU neuron's pre-activation stays negative, \(ReLU(z)=0\) and \(ReLU'(z)=0\), so it receives no useful gradient and stops learning. Leaky ReLU assigns a small negative slope, \(f(z)=0.01z\) for \(z<0\), allowing some gradient to keep flowing.

Q5. When should Sigmoid and Softmax be used?

Use sigmoid for binary classification or independent multi-label outputs, because each output is treated independently. Use softmax for mutually exclusive multiclass classification, because all class probabilities are normalised so that \(\sum_i P_i=1\).

Q6. Which activations are most prone to the vanishing-gradient problem?

Sigmoid and tanh, because they saturate for large absolute inputs where their derivatives approach zero. ReLU reduces the problem for positive inputs since its derivative is exactly 1, although it can suffer from dying neurons on the negative side.

(6) Why the sums differ

Sigmoid is applied element-wise. Each output is computed from its own \(z_i\) alone:

\[ \sigma(z_i)=\frac{1}{1+e^{-z_i}} \qquad \text{— no other } z_j \text{ appears} \]

Nothing couples the three values, so their sum can be anything in \((0,3)\). Here it is \(1.6497\).

Softmax is applied to the vector. Every output shares the same denominator:

\[ \hat y_i=\frac{e^{z_i}}{\sum_j e^{z_j}} \qquad\Longrightarrow\qquad \sum_i \hat y_i = \frac{\sum_i e^{z_i}}{\sum_j e^{z_j}} = 1 \]

The sum is 1 by construction — it is an algebraic identity, not a coincidence of these numbers.

\[ \boxed{ \text{Sigmoid: independent outputs} \;\Rightarrow\; \text{multi-label} } \] \[ \boxed{ \text{Softmax: competing outputs} \;\Rightarrow\; \text{mutually exclusive classes} } \]

Notice also how softmax exaggerates differences: the logits \(-1,0,2\) are evenly spread, but the probabilities are \(0.04,\,0.11,\,0.84\). Exponentiating amplifies the gap — which is why a confident softmax can look far more certain than its logits suggest.
