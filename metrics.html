1. First understand TP, TN, FP and FN

Suppose the positive class is "disease present". Every prediction falls into one of four boxes:

RealityPredictionName
DiseaseDiseaseTP — True Positive
No diseaseNo diseaseTN — True Negative
No diseaseDiseaseFP — False Positive
DiseaseNo diseaseFN — False Negative

The easiest intuition:

\[ \textbf{FP} : \text{the model raises a false alarm} \] \[ \textbf{FN} : \text{the model misses something that is actually there} \] 
                    PREDICTED
                 Positive   Negative
              ┌──────────┬──────────┐
     Positive │    TP    │    FN    │   ← all the real positives
  A           │  (found) │ (missed) │
  C           ├──────────┼──────────┤
  T  Negative │    FP    │    TN    │   ← all the real negatives
  U           │ (alarm)  │  (quiet) │
  A           └──────────┴──────────┘
  L                 ↑
            everything called positive

Every metric below is just a different ratio of these four numbers. Read the diagram once and you can rebuild all of them: precision divides by a column, recall and specificity divide by a row.

2. Accuracy

Out of all predictions, how many were correct?
\[ \boxed{ Accuracy=\frac{TP+TN}{TP+TN+FP+FN} } \]

If 90 out of 100 samples were classified correctly, \(Accuracy = 90/100 = 90\%\).

Significance — and the trap

Accuracy is useful when the classes are reasonably balanced. It becomes badly misleading on imbalanced datasets.

If 99% of patients are healthy, a model that predicts "healthy" for everyone scores \(99\%\) accuracy while detecting zero diseased patients. Its recall is \(0\).

This is exactly why precision and recall exist — they refuse to be fooled by the majority class, because neither of them has \(TN\) anywhere in its formula.

3. Precision

Of everything the model predicted as positive, how many were actually positive?
\[ \boxed{ Precision=\frac{TP}{TP+FP} } \]

The denominator is everything predicted positive — the left column of the confusion matrix.

High precision means few false positives. If a spam filter marks 100 emails as spam and 95 really are spam, \(Precision = 95/100 = 95\%\).

\[ \boxed{ \text{Precision matters when false alarms are costly.} } \]

Spam filtering is the standard example: a legitimate email silently sent to the spam folder is far worse than a spam email reaching the inbox.

4. Recall

Also called Sensitivity or the True Positive Rate.

Of all the actual positives, how many did the model successfully find?
\[ \boxed{ Recall=\frac{TP}{TP+FN} } \]

The denominator is everything actually positive — the top row of the confusion matrix.

High recall means few false negatives. If 100 patients actually have a disease and the model detects 90, \(Recall = 90/100 = 90\%\).

\[ \boxed{ \text{Recall matters when missing a positive case is dangerous.} } \]

Medical screening is the standard example: a missed tumour is far worse than a false alarm that a second test clears.

5. Precision vs recall — the easiest distinction

Memorise these two questions and you never need to re-derive the formulas:

\[ \boxed{ Precision:\ \text{When I say YES, how often am I right?} } \] \[ \boxed{ Recall:\ \text{Of all the real YES cases, how many did I find?} } \]
PrecisionRecall
Denominator\(TP+FP\)\(TP+FN\)
Which error it punishesFP — false alarmsFN — misses
Direction in the matrixcolumn (what I predicted)row (what was real)
Classic use casespam filteringdisease screening

Both ignore \(TN\) entirely. That is the feature, not an oversight — it is what makes them survive class imbalance.

6. F1 score

Raising precision often lowers recall and vice versa, so a single number that respects both is useful. F1 is the harmonic mean:

\[ \boxed{ F_1 = 2\,\frac{Precision\times Recall}{Precision+Recall} } \]

Why harmonic and not ordinary average?

Because F1 should only be high when both are high. Take an extreme case:

\[ P=1.0, \qquad R=0.1 \]
MeanValueVerdict
Ordinary (arithmetic)\(\frac{1.0+0.1}{2}=0.55\)misleadingly reasonable
Harmonic (F1)\(\frac{2(1)(0.1)}{1.1}\approx0.182\)honest about the imbalance

The harmonic mean is dragged down by the smaller of the two values, which is exactly the behaviour wanted here.

A shortcut worth knowing

Substituting the definitions and simplifying gives F1 directly from the confusion matrix, with no need to compute \(P\) and \(R\) first:

\[ \boxed{ F_1 = \frac{2\,TP}{2\,TP+FP+FN} } \]

Faster under exam pressure, and it makes the interpretation obvious: F1 counts the two error types \(FP\) and \(FN\) against the true positives, and never looks at \(TN\) at all.

7. Specificity

Of all actual negative examples, how many did we correctly identify as negative?
\[ \boxed{ Specificity=\frac{TN}{TN+FP} } \]

Also called the True Negative Rate. Recall focuses on the positives; specificity is its mirror image, focusing on the negatives.

MetricRow of the matrixAsks about
Recall (sensitivity)actual positives\(TP/(TP+FN)\)
Specificityactual negatives\(TN/(TN+FP)\)

8. Worked exam-style question

QuestionA binary classifier produces the confusion matrix below. Calculate accuracy, precision, recall, F1 score and specificity, and briefly interpret the results.
Predicted PositivePredicted Negative
Actual Positive324
Actual Negative856

Step 1 — read off the four values

\[ TP=32, \qquad FN=4, \qquad FP=8, \qquad TN=56 \] \[ \text{Total} = 32+4+8+56 = 100 \]

Step 2 — Accuracy

\[ Accuracy=\frac{TP+TN}{\text{Total}}=\frac{32+56}{100} \]
\[ \boxed{ Accuracy = 0.88 = 88\% } \]

Step 3 — Precision

\[ Precision=\frac{32}{32+8}=\frac{32}{40} \]
\[ \boxed{ Precision = 0.80 = 80\% } \]

When the model predicts positive, it is correct \(80\%\) of the time.

Step 4 — Recall

\[ Recall=\frac{32}{32+4}=\frac{32}{36} \]
\[ \boxed{ Recall \approx 0.889 = 88.9\% } \]

The model finds about \(88.9\%\) of all real positive cases.

Step 5 — F1

\[ F_1 = 2\,\frac{(0.80)(0.889)}{0.80+0.889} = \frac{1.4222}{1.6889} \]
\[ \boxed{ F_1 \approx 0.842 = 84.2\% } \]

Check with the shortcut: \(\dfrac{2(32)}{2(32)+8+4}=\dfrac{64}{76}=0.8421\) ✓ — same answer, one line.

Step 6 — Specificity

\[ Specificity=\frac{56}{56+8}=\frac{56}{64} \]
\[ \boxed{ Specificity = 0.875 = 87.5\% } \]

Interpretation

MetricValueReading
Accuracy88.0%correct on most samples overall
Precision80.0%1 in 5 positive calls is a false alarm
Recall88.9%misses about 1 in 9 real positives
F184.2%reasonably balanced, precision is the weaker side
Specificity87.5%correctly clears most true negatives

Recall exceeds precision here, so the classifier leans toward predicting positive — it catches most real cases at the cost of some false alarms. If false alarms were expensive, raising the decision threshold would trade some of that recall back for precision.

9. What happens when the classification threshold changes?

Suppose a positive prediction means \(P(y=1)\ge0.5\). Moving that threshold moves precision and recall in opposite directions.

ThresholdEffectPrecisionRecall
Lowered (e.g. to 0.3)more samples called positive↓↑
Raised (e.g. to 0.7)fewer samples called positive↑↓

Lowering the threshold catches more real positives (recall up) but also produces more false alarms (precision down). Raising it does the reverse.

  threshold →  0.1   0.3   0.5   0.7   0.9
  Recall       ████████████████▌
               high ─────────────────────► low
  Precision                ◄───────────────────── 
               low  ─────────────────────► high

  every threshold gives one (Recall, Precision) point
  → sweep them all and you trace the PR curve
\[ \boxed{ \text{This trade-off is exactly what AP measures.} } \]

10. AP — Average Precision

AP is used in retrieval and, most often for this course, in object detection.

First decide whether each predicted box is a TP or an FP, using two conditions:

  1. The predicted class is correct.
  2. The overlap with a ground-truth object is sufficient, measured by IoU — commonly \(IoU\ge0.5\).

Then sort the detections from highest to lowest confidence. Sweeping down that sorted list gives a sequence of \((Recall,\ Precision)\) points, which form the precision–recall curve. Average Precision is the area under it:

\[ \boxed{ AP \approx \text{Area under the precision–recall curve} } \]
  Precision
   1.0 │●──●──●
       │        ╲●──●
       │              ╲●───●
       │                     ╲●──●
       │                           ╲●
   0.0 └──────────────────────────────► Recall
       0.0                          1.0
            AP = the shaded area under this curve

A high AP means the detector keeps its precision high even as recall increases — it finds most of the objects without flooding the output with false detections.

11. mAP — mean Average Precision

For multiple classes, compute AP independently for each class, then average:

\[ \boxed{ mAP = \frac{1}{C}\sum_{c=1}^{C} AP_c } \]

Example

ClassAP
car0.90
person0.80
dog0.70
mAP0.80
\[ mAP = \frac{0.90+0.80+0.70}{3} = \boxed{0.80} = 80\% \]

Results are often quoted at a fixed IoU threshold (mAP@0.5) or averaged over several thresholds (mAP@[.5:.95]). Always state which, because the numbers are not comparable across conventions.
