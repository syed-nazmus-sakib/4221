  • Cell architecture → equations

    • LSTM cell: architecture → equations

    At time \(t\), the old hidden state \(h_{t-1}\) and current input \(x_t\) feed all four gate calculations. The old cell state \(C_{t-1}\) follows the memory path.

    h(t−1), x(t) ──→ f, i, C̃, o
C(t−1) ──× f──┐
               + ──→ C(t) ──tanh──× o──→ h(t)
       C̃ ──× i──┘
    1. Forget: old memory path\(f_t=\sigma(W_f^{(h)}h_{t-1}+W_f^{(x)}x_t+b_f)\). Multiply this gate by \(C_{t-1}\) to keep part of the old memory.
    2. Input: new memory valve\(i_t=\sigma(W_i^{(h)}h_{t-1}+W_i^{(x)}x_t+b_i)\). This controls how much new information enters.
    3. Candidate: proposed new memory\(\tilde C_t=\tanh(W_c^{(h)}h_{t-1}+W_c^{(x)}x_t+b_c)\). This branch uses tanh.
    4. Merge the two memory paths\(C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t\). The two products meet at the plus sign in the diagram.
    5. Output: exposure valve\(o_t=\sigma(W_o^{(h)}h_{t-1}+W_o^{(x)}x_t+b_o)\). This gate decides how much of the updated memory to show.
    6. Hidden state: cell output\(h_t=o_t\odot\tanh(C_t)\). Send \(h_t\) and \(C_t\) to the next time step.

    \(\odot\) is element-wise multiplication. Compute each matrix product separately before applying sigmoid or tanh.

    The final asks for the RNN sequence types, an LSTM-cell diagram, and then the full numerical chain \(f_t,i_t,\tilde C_t,C_t,o_t,h_t\).

    (a) RNN types based on input-output sequence structure

    1. One-to-one — One input → one output. Example: image classification.
    2. One-to-many — One input → sequence of outputs. Example: image captioning.
    3. Many-to-one — Sequence input → one output. Example: sentiment classification.
    4. Many-to-many — Sequence input → sequence output. Example: machine translation.
