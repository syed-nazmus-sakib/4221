Question 3 — Retake Exam, Q2

Most versatile numerical CNN question: stride-2 same conv, DS block, valid stride-2 conv, FC, plus receptive field with / without pooling.

The full question

Retake Exam · CNN · Question 2

The input is

\[ 64\times64\times3. \]

The architecture is

\[ \text{Conv1: standard, 32 filters, }3\times3,\text{ same},\ s=2 \] \[ \rightarrow \text{Conv2-DW: }3\times3,\text{ same},\ s=1 \] \[ \rightarrow \text{Conv2-PW: 64 filters, }1\times1,\ s=1 \] \[ \rightarrow \text{Conv3: standard, 128 filters, }3\times3,\text{ valid},\ s=2 \] \[ \rightarrow \text{Flatten} \rightarrow FC(10). \]

Every filter and FC neuron has one bias.

  • (a)Determine the output height and width after Conv1 and Conv3. Also determine the flatten size.
  • (b)Calculate the parameters in Conv1, Conv2-DW, Conv2-PW, Conv3, FC, and the network total.
  • (c)Replace Conv2-DW + Conv2-PW with a standard \(3\times3\) convolution producing 64 channels. Calculate its parameters and the reduction ratio of the depthwise-separable design.
  • (d)Determine the receptive field after two consecutive \(3\times3\), stride-1 convolutions. Then determine it again when a \(2\times2\), stride-2 max-pooling layer is inserted between the two convolutions.

Architecture

\[ 64\times64\times3 \rightarrow \text{Conv1: }3\times3,\ 32\text{ filters, same, s=2} \] \[ \rightarrow \text{Conv2-DW: }3\times3,\ 32\text{ ch, same, s=1} \rightarrow \text{Conv2-PW: }1\times1,\ 64\text{ filters} \] \[ \rightarrow \text{Conv3: }3\times3,\ 128\text{ filters, valid, s=2} \rightarrow \text{Flatten} \rightarrow \text{FC }10. \]

Q2(a) — Output size after Conv1 and Conv3

\[ n_{out} = \left\lfloor \frac{n+2p-k}{s} \right\rfloor+1. \]

Conv1 — n=64, k=3, p=1 (same), s=2

\[ n_{out} = \left\lfloor \frac{64+2(1)-3}{2} \right\rfloor+1 = \left\lfloor \frac{63}{2} \right\rfloor+1 = 31+1 = 32. \]
\[ \boxed{Conv1=32\times32\times32} \]

Conv2-DW / PW

Same, stride 1: \(32\times32\times32.\) Pointwise changes only channels:

\[ \boxed{32\times32\times64}. \]

Conv3 — n=32, k=3, p=0 (valid), s=2

\[ n_{out} = \left\lfloor \frac{32-3}{2} \right\rfloor+1 = \left\lfloor \frac{29}{2} \right\rfloor+1 = 14+1 = 15. \]
\[ \boxed{Conv3=15\times15\times128} \]

Flatten \(15\times15\times128 = 225\times128\):

\[ \boxed{28{,}800}. \]

Q2(b) — Parameter counts

Conv1

\[ (3\times3\times3+1)\times32 = (27+1)\times32 = 28\times32 \]
\[ \boxed{896} \]

Conv2-DW

\[ (3\times3\times1+1)\times32 = 10\times32 \]
\[ \boxed{320} \]

Conv2-PW

\[ (1\times1\times32+1)\times64 = 33\times64 \]
\[ \boxed{2{,}112} \]

Conv3

Input channels 64, output 128, kernel \(3\times3\): \(3\times3\times64 = 576\) + bias \(= 577.\)

\[ 577\times128 \quad \boxed{73{,}856} \]

FC

\[ 28{,}800\times10+10 = 288{,}000+10 \]
\[ \boxed{288{,}010} \]

Total

\[ 896+320+2112+73{,}856+288{,}010. \quad 896+320=1216,\;1216+2112=3328,\;3328+73{,}856=77{,}184 \quad \boxed{365{,}194} \]

Q2(c) — Replace Conv2 with standard convolution

Standard \(3\times3\), in 32, out 64: \(3\times3\times32 = 288\) + bias \(= 289.\)

\[ 289\times64 \quad \boxed{18{,}496} \]

DS Conv2: \(320+2112 = \boxed{2{,}432}.\)

\[ \frac{18{,}496}{2432} \approx 7.61. \]
\[ \boxed{\text{standard uses about }7.61\times\text{ more parameters}} \]
\[ \frac{2432}{18{,}496}\times100 \approx 13.15\%. \]
\[ \boxed{13.15\%} \quad \boxed{86.85\%\text{ saving}}. \]

Bias-free approximation: \(\frac1{64}+\frac1{9} \approx 12.7\%.\).

Q2(d) — Receptive field

\[ \boxed{ r_l = r_{l-1} + (k_l-1)j_{l-1} } \qquad \boxed{ j_l=j_{l-1}s_l } \qquad r_0=1,\; j_0=1. \]

Case 1 — Two consecutive 3×3, stride-1 convolutions

Conv1: \(r_1 = 1+(3-1)(1) = 3.\) Jump \(j_1 = 1.\) So \(\boxed{RF=3\times3}\). Conv2: \(r_2 = 3+(3-1)(1) = 5.\)

\[ \boxed{RF=5\times5} \]

Case 2 — Conv → Pool → Conv (3×3 s=1, 2×2 Pool s=2, 3×3 s=1)

First conv: \(r_1=3,\; j_1=1.\) Pooling k=2 s=2: \(r_2 = 3+(2-1)(1) = 4.\) Jump \(j_2 = 2.\) Second conv:

\[ r_3 = 4+(3-1)(2) = 4+4 = 8. \]
\[ \boxed{RF=8\times8} \]
Pooling with stride 2 increases the spacing between adjacent features. Therefore each later convolution covers a much larger region of the original input. Without pooling \(5\times5\); with intermediate stride-2 pool \(8\times8\).

What these three questions tell us

Pattern 1 — Output dimension

\[ \boxed{ \left\lfloor \frac{n+2p-k}{s} \right\rfloor+1 } \]

Especially same / valid, stride 1 / 2, max pooling.

Pattern 2 — Standard conv parameters

\[ \boxed{ K_hK_wC_{in}C_{out}+C_{out} } \qquad \boxed{ (K_hK_wC_{in}+1)C_{out} } \]

Most common mistake: forgetting every filter spans every input channel.

Pattern 3 — Depthwise

\[ \boxed{ (K_hK_w+1)C_{in} } \]

Pattern 4 — Pointwise

\[ \boxed{ (C_{in}+1)C_{out} } \]

Pattern 5 — DS vs standard

Calculate \(P_{DS}=P_{DW}+P_{PW}\) vs \(P_{standard}\). Very high-priority exam skill.

Pattern 6 — FC explosion

Once you flatten \(H\times W\times C\), FC dominates. In-course FC1 = 12,544,100 while DS Conv2 = only 1,040. Whole-network saving from DS looks small because FC1 alone is ~12.5M.

Pattern 7 — Computation ≠ parameters

Parameter count depends on kernel/channels. Computation additionally multiplies by \(H_{out}W_{out}\).

Pattern 8 — Receptive field

\[ r_l=r_{l-1}+(k_l-1)j_{l-1} \qquad j_l=j_{l-1}s_l. \]
