Regression Problem 4 — Bounded Regression: ReLU + Sigmoid + MSE

\(2\rightarrow2\rightarrow1\) with ReLU hidden units and a Sigmoid output scored by plain MSE. This is the one where \(\delta^{(2)}=\hat y-y\) is wrong — the sigmoid derivative does not cancel, so the chain rule has to be applied by hand. Ends with a summary of all four regression patterns.

The full question

Fresh regression practice · Problem 4 · 2 → 2 → 1 · ReLU hidden, Sigmoid output

Consider a network \(2\rightarrow2\rightarrow1\) with ReLU hidden units and a Sigmoid output. Given:

\[ x=\begin{bmatrix} 1 \\ 0.5 \end{bmatrix}, \qquad y=0.8 \] \[ W^{(1)}=\begin{bmatrix} 0.4 & -0.2 \\ 0.6 & 0.4 \end{bmatrix}, \qquad b^{(1)}=\begin{bmatrix} 0.1 \\ -0.1 \end{bmatrix} \] \[ W^{(2)}=\begin{bmatrix} 0.5 \\ -0.3 \end{bmatrix}, \qquad b^{(2)}=0.1, \qquad \eta=0.2 \]

with the loss

\[ \boxed{ L=(\hat y-y)^{2} } \]

Compute the complete forward pass and backpropagation:

  • (a)The forward pass — \(z^{(1)}\), \(h\), \(z^{(2)}\) and \(\hat y\).
  • (b)The loss.
  • (c)The output delta \(\delta^{(2)}\).
  • (d)The gradients of \(W^{(2)},b^{(2)}\).
  • (e)The hidden delta \(\delta^{(1)}\).
  • (f)The gradients of \(W^{(1)},b^{(1)}\).
A sigmoid output only makes sense for regression when the target is bounded in \([0,1]\) — which \(y=0.8\) is. Note also that \(\eta=0.2\) is given but the question stops at the gradients, so no update is required; see the optional section if you want it anyway.

The network at a glance

Before solving: why this one is different

In ANN-5, ANN-6 and ANN-7 the output was linear, so \(\partial\hat y/\partial z^{(2)}=1\) and the output delta was just the loss derivative. Here the output passes through a sigmoid, so that factor is no longer 1:

\[ \delta^{(2)}=\underbrace{\frac{\partial L}{\partial\hat y}}_{2(\hat y-y)}\cdot \underbrace{\frac{\partial\hat y}{\partial z^{(2)}}}_{\hat y(1-\hat y)} \]
\[ \boxed{ \text{You may \textbf{not} write } \delta^{(2)}=\hat y-y \text{ here.} } \]

That shortcut is only valid for Sigmoid + BCE (see ANN-1) or Softmax + CCE (see ANN-4), where the loss is chosen precisely so that \(\sigma'\) cancels. Pair a sigmoid with an ordinary squared error and nothing cancels — you carry both factors.

   x (2)             h (2)              y^ (1)
  ┌─────┐  W(1)ᵀ    ┌──────┐   W(2)ᵀ   ┌─────────┐
  │  1  │ ────────► │ ReLU │ ────────► │ Sigmoid │ ─► y^ ─► (y^ − y)² ─► L
  │ 0.5 │  + b(1)   │ ReLU │   + b(2)  └─────────┘        y = 0.8
  └─────┘           └──────┘
       2×2                  2×1     backward: × σ'(z) AND × ReLU'(z)

(a) Forward pass

\[ (W^{(1)})^{T}=\begin{bmatrix} 0.4 & 0.6 \\ -0.2 & 0.4 \end{bmatrix} \qquad z^{(1)}=(W^{(1)})^{T}x+b^{(1)} \]

Hidden pre-activations

\[ z^{(1)}_1 = 0.4(1)+0.6(0.5)+0.1 = 0.4+0.3+0.1 \qquad \boxed{ z^{(1)}_1=0.8 } \] \[ z^{(1)}_2 = -0.2(1)+0.4(0.5)-0.1 = -0.2+0.2-0.1 \qquad \boxed{ z^{(1)}_2=-0.1 } \]

Apply ReLU — the second unit is negative and gets clipped:

\[ \boxed{ h=\begin{bmatrix} 0.8 \\ 0 \end{bmatrix} } \]

Output pre-activation

\[ z^{(2)} = 0.5(0.8)-0.3(0)+0.1 = 0.4+0.1 \qquad \boxed{ z^{(2)}=0.5 } \]

Unlike the previous three problems, this is not the prediction. Apply the sigmoid:

\[ \hat y=\sigma(0.5)=\frac{1}{1+e^{-0.5}} \]
\[ \boxed{ \hat y \approx 0.62246 } \]

(b) Loss

Note there is no \(\tfrac12\) on this loss:

\[ L=(\hat y-y)^{2}=(0.62246-0.8)^{2}=(-0.17754)^{2} \]
\[ \boxed{ L \approx 0.03152 } \]

(c) Output delta — chain rule by hand

This is the main lesson of the page. Two factors, neither of which cancels:

\[ \delta^{(2)}=\frac{\partial L}{\partial\hat y}\cdot\frac{\partial\hat y}{\partial z^{(2)}} \]

Factor 1 — the loss derivative

\[ \frac{\partial L}{\partial\hat y}=2(\hat y-y)=2(0.62246-0.8) \qquad \approx -0.35508 \]

Factor 2 — the sigmoid derivative

Use the activation you already computed; no need to touch \(z^{(2)}\) again:

\[ \sigma'(z^{(2)})=\hat y(1-\hat y)=0.62246(1-0.62246)=0.62246(0.37754) \qquad \approx 0.23500 \]

Multiply them

\[ \delta^{(2)}=(-0.35508)(0.23500) \]
\[ \boxed{ \delta^{(2)} \approx -0.08345 } \]

Why this matters beyond the arithmetic

Compare the two factors. The raw error is \(-0.355\), but the sigmoid derivative shrinks it to \(-0.083\) — a factor of four smaller. And \(\sigma'\) peaks at only \(0.25\), so every sigmoid output damps the gradient by at least \(4\times\). If the output saturates (\(\hat y\) near 0 or 1), \(\sigma'\to0\) and learning stalls even when the prediction is badly wrong.

\[ \text{Sigmoid + BCE:}\;\; \delta^{(2)}=\hat y-y \quad\text{(the } \sigma' \text{ cancels)} \] \[ \text{Sigmoid + MSE:}\;\; \delta^{(2)}=2(\hat y-y)\,\hat y(1-\hat y) \quad\text{(it does not)} \]

That is exactly why classification uses cross-entropy rather than squared error — not tradition, but to remove this \(\sigma'\) factor and keep the gradient alive.

(d) Output gradients

\[ \nabla W^{(2)}=h\,\delta^{(2)}=\begin{bmatrix} 0.8 \\ 0 \end{bmatrix}(-0.08345) \]
\[ \boxed{ \nabla W^{(2)} \approx \begin{bmatrix} -0.06676 \\ 0 \end{bmatrix} } \qquad \boxed{ \nabla b^{(2)} = \delta^{(2)} \approx -0.08345 } \]

Second entry zero again — the dead ReLU unit contributes nothing, same as ANN-6.

(e) Hidden delta

\[ W^{(2)}\delta^{(2)}=\begin{bmatrix} 0.5 \\ -0.3 \end{bmatrix}(-0.08345) \approx \begin{bmatrix} -0.04172 \\ 0.02503 \end{bmatrix} \]

Apply the ReLU derivative — 1 where \(z^{(1)}>0\), 0 where \(z^{(1)}<0\):

\[ z^{(1)}=\begin{bmatrix} 0.8 \\ -0.1 \end{bmatrix} \;\Rightarrow\; \mathrm{ReLU}'(z^{(1)})=\begin{bmatrix} 1 \\ 0 \end{bmatrix} \] \[ \delta^{(1)}=\begin{bmatrix} -0.04172 \\ 0.02503 \end{bmatrix}\odot\begin{bmatrix} 1 \\ 0 \end{bmatrix} \]
\[ \boxed{ \delta^{(1)} \approx \begin{bmatrix} -0.04172 \\ 0 \end{bmatrix} } \]

Note how small this is — the sigmoid already shrank the signal by \(4\times\) before it even reached the hidden layer.

(f) First-layer gradients

\[ \nabla W^{(1)}=x\,(\delta^{(1)})^{T} =\begin{bmatrix} 1 \\ 0.5 \end{bmatrix}\begin{bmatrix} -0.04172 & 0 \end{bmatrix} \]
\[ \text{Row 1: } 1(-0.04172)=-0.04172,\qquad 1(0)=0 \] \[ \text{Row 2: } 0.5(-0.04172)=-0.02086,\qquad 0.5(0)=0 \]
\[ \boxed{ \nabla W^{(1)} \approx \begin{bmatrix} -0.04172 & 0 \\ -0.02086 & 0 \end{bmatrix} } \qquad \boxed{ \nabla b^{(1)} = \delta^{(1)} \approx \begin{bmatrix} -0.04172 \\ 0 \end{bmatrix} } \]

Row 2 is exactly half of row 1, because \(x_2=0.5x_1\).

If you were also asked to update

The question stops at the gradients, so \(\eta=0.2\) is never used — do not invent an update step in the exam. But for completeness, \(\theta_{\text{new}}=\theta_{\text{old}}-0.2\nabla\theta\) gives:

\[ W^{(2)}_{\text{new}} \approx \begin{bmatrix} 0.51335 \\ -0.3 \end{bmatrix} \qquad b^{(2)}_{\text{new}} \approx 0.11669 \] \[ W^{(1)}_{\text{new}} \approx \begin{bmatrix} 0.40834 & -0.2 \\ 0.60417 & 0.4 \end{bmatrix} \qquad b^{(1)}_{\text{new}} \approx \begin{bmatrix} 0.10834 \\ -0.1 \end{bmatrix} \]

The changes are tiny — fourth decimal place — precisely because the sigmoid throttled the gradient.

Final answer sheet

\[ \boxed{ z^{(1)}=\begin{bmatrix} 0.8 \\ -0.1 \end{bmatrix} } \quad \boxed{ h=\begin{bmatrix} 0.8 \\ 0 \end{bmatrix} } \quad \boxed{ z^{(2)}=0.5 } \quad \boxed{ \hat y \approx 0.62246 } \quad \boxed{ L \approx 0.03152 } \] \[ \boxed{ \frac{\partial L}{\partial\hat y} \approx -0.35508 } \quad \boxed{ \sigma' \approx 0.23500 } \quad \boxed{ \delta^{(2)} \approx -0.08345 } \] \[ \boxed{ \nabla W^{(2)} \approx \begin{bmatrix} -0.06676 \\ 0 \end{bmatrix} } \quad \boxed{ \nabla b^{(2)} \approx -0.08345 } \quad \boxed{ \delta^{(1)} \approx \begin{bmatrix} -0.04172 \\ 0 \end{bmatrix} } \] \[ \boxed{ \nabla W^{(1)} \approx \begin{bmatrix} -0.04172 & 0 \\ -0.02086 & 0 \end{bmatrix} } \quad \boxed{ \nabla b^{(1)} \approx \begin{bmatrix} -0.04172 \\ 0 \end{bmatrix} } \]

All four regression patterns

These four pages exist to make one point, and it is the opposite of the reflex you built on the classification problems:

\[ \boxed{ \text{Regression does \textbf{not} automatically mean } \delta^{(2)}=\hat y-y. } \]

You have to read both the output activation and the exact printed form of the loss.

The standard setup

For the most common regression network:

\[ \boxed{ \text{Hidden activation} \rightarrow \text{Linear output} \rightarrow \text{MSE} } \]

the hidden activation can be ReLU, tanh, or even linear — and because the output is linear, the output delta is always just the loss derivative, with no activation factor. A non-linear output (like ANN-8's sigmoid) is the exception, and it is the case that needs the chain rule spelled out.
