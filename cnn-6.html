(c) Replace Conv3 with DS block

Careful: Conv3 input is \(\boxed{31\times31\times64}\), output \(15\times15\times128\). Replacement: \(3\times3\) DW valid s=2 + \(1\times1\) PW →128.

DW — 10×64

\[ P_{DW} = 10\times64 \quad \boxed{640} \]

PW — 65×128

\[ P_{PW} = 65\times128 \quad \boxed{8320} \]
\[ P_{DS} = 640+8320 \quad \boxed{8960} \quad \text{vs } \boxed{73{,}856} \]
\[ \frac{73{,}856}{8{,}960} \approx 8.24. \]
\[ \boxed{ \text{standard uses about }8.24\times \text{ more parameters} } \]
\[ \frac{8960}{73856}\times100 \approx 12.13\%. \]
\[ \boxed{87.87\%} \quad \boxed{87.9\%} \]

(d) Computational cost

Output spatial \(15\times15.\)

Original standard Conv3

\[ MAC_{\text{std}} = 15\times15\times9\times64\times128 = 225\times9\times64\times128. \]
\[ \boxed{ MAC_{\text{std}} = 16{,}588{,}800 } \quad \boxed{16.59M} \]

DW / PW

\[ MAC_{DW} = 225\times9\times64. \quad \boxed{129{,}600} \]
\[ MAC_{PW} = 225\times64\times128. \quad \boxed{1{,}843{,}200} \]
\[ MAC_{DS} = 129{,}600+1{,}843{,}200 \quad \boxed{ 1{,}972{,}800 } \quad 1.97M. \]
\[ \frac{16{,}588{,}800}{1{,}972{,}800} \approx 8.41. \]
\[ \boxed{ \text{standard requires about }8.41\times \text{more MACs} } \]
\[ \frac{1{,}972{,}800}{16{,}588{,}800}\times100 \approx 11.89\%. \]
\[ \boxed{88.11\%} \]

Params ≈87.87% vs compute ≈88.11% — close, not identical.

(e) Receptive field after Pool2 + sheet

\[ \boxed{ r_l=r_{l-1}+(k_l-1)j_{l-1} } \qquad \boxed{ j_l=j_{l-1}s_l } \quad r_0=1,\ j_0=1. \]
