Regression Problem 2 — ReLU Hidden, Linear Output

\(2\rightarrow2\rightarrow1\) with ReLU hidden units and a linear output, scored with \(\tfrac12(\hat y-y)^{2}\). Two lessons: the \(\tfrac12\) changes \(\delta^{(2)}\), and one hidden unit is dead — so part of the network learns nothing. Ends with a second forward pass showing the loss actually fall.

The full question

Fresh regression practice · Problem 2 · 2 → 2 → 1 · ReLU hidden, linear output

Consider a network \(2\rightarrow2\rightarrow1\) with ReLU hidden units and a linear output. Given:

\[ x=\begin{bmatrix} 1 \\ -2 \end{bmatrix}, \qquad y=1 \] \[ W^{(1)}=\begin{bmatrix} 0.5 & -0.4 \\ 0.2 & 0.3 \end{bmatrix}, \qquad b^{(1)}=\begin{bmatrix} 0.1 \\ 0.2 \end{bmatrix} \] \[ W^{(2)}=\begin{bmatrix} 0.7 \\ -0.5 \end{bmatrix}, \qquad b^{(2)}=0.1, \qquad \eta=0.1 \]

Use the loss

\[ \boxed{ L=\tfrac12(\hat y-y)^{2} } \]

Compute:

  • (a)The complete forward pass — \(z^{(1)}\), \(h\) and \(\hat y\).
  • (b)The loss.
  • (c)The full backpropagation — both deltas and all four gradients.
  • (d)Update every parameter.
  • (e)Perform one new forward pass and compare the loss.

The network at a glance

Before solving: the \(\tfrac12\) trap

ANN-5 used \(L=(\hat y-y)^{2}\). This one uses \(L=\tfrac12(\hat y-y)^{2}\). That single factor changes the output delta:

Loss as written\(\partial L/\partial\hat y\)Where you saw it
\(L=(\hat y-y)^{2}\)\(2(\hat y-y)\)ANN-5
\(L=\tfrac12(\hat y-y)^{2}\)\(\hat y-y\)this page

The \(\tfrac12\) exists purely so that the 2 from the power rule cancels and the delta comes out clean. Both conventions are common, so read the loss as printed on the paper — a factor of 2 in every gradient is a whole question's worth of marks.

   x (2)             h (2)              y^ (1)
  ┌─────┐  W(1)ᵀ    ┌──────┐   W(2)ᵀ   ┌────────┐
  │  1  │ ────────► │ ReLU │ ────────► │ linear │ ──► y^ ──► ½(y^ − y)² ──► L
  │ -2  │  + b(1)   │ ReLU │   + b(2)  └────────┘         y = 1
  └─────┘           └──────┘
       2×2                  2×1        watch for a dead ReLU unit

(a) Forward pass

\[ (W^{(1)})^{T}=\begin{bmatrix} 0.5 & 0.2 \\ -0.4 & 0.3 \end{bmatrix} \qquad z^{(1)}=(W^{(1)})^{T}x+b^{(1)} \]

First neuron

\[ 0.5(1)+0.2(-2)+0.1 = 0.5-0.4+0.1 \qquad \boxed{ z^{(1)}_1 = 0.2 } \]

Second neuron

\[ -0.4(1)+0.3(-2)+0.2 = -0.4-0.6+0.2 \qquad \boxed{ z^{(1)}_2 = -0.8 } \]
\[ z^{(1)}=\begin{bmatrix} 0.2 \\ -0.8 \end{bmatrix} \]

Apply ReLU

\(\mathrm{ReLU}(z)=\max(0,z)\). The second pre-activation is negative, so it is clipped to zero:

\[ \boxed{ h=\begin{bmatrix} 0.2 \\ 0 \end{bmatrix} } \]

The second hidden neuron is inactive. Remember this — it will zero out a whole slice of the gradients in part (c).

Linear output

\[ \hat y = 0.7(0.2)-0.5(0)+0.1 = 0.14+0.1 \]
\[ \boxed{ \hat y = 0.24 } \]

(b) Loss

\[ L=\tfrac12(0.24-1)^{2}=\tfrac12(-0.76)^{2}=\tfrac12(0.5776) \]
\[ \boxed{ L = 0.2888 } \]

(c) Backpropagation

Output delta

With the \(\tfrac12\) in front, the 2 from the power rule cancels, and the linear output contributes a derivative of 1:

\[ L=\tfrac12(\hat y-y)^{2} \qquad\Longrightarrow\qquad \boxed{ \delta^{(2)}=\hat y-y } \] \[ \delta^{(2)}=0.24-1 \]
\[ \boxed{ \delta^{(2)} = -0.76 } \]
\[ (\hat y-y)^{2} \;\Rightarrow\; 2(\hat y-y) \qquad\text{but}\qquad \tfrac12(\hat y-y)^{2} \;\Rightarrow\; (\hat y-y) \]

Output gradients

\[ \nabla W^{(2)}=h\,\delta^{(2)}=\begin{bmatrix} 0.2 \\ 0 \end{bmatrix}(-0.76) \]
\[ \boxed{ \nabla W^{(2)}=\begin{bmatrix} -0.152 \\ 0 \end{bmatrix} } \qquad \boxed{ \nabla b^{(2)}=-0.76 } \]

The second entry is zero because \(h_2=0\) — a dead unit sends nothing forward, so the weight reading from it learns nothing.

Hidden delta

First push the error back through \(W^{(2)}\):

\[ W^{(2)}\delta^{(2)}=\begin{bmatrix} 0.7 \\ -0.5 \end{bmatrix}(-0.76) =\begin{bmatrix} -0.532 \\ 0.380 \end{bmatrix} \]

Then apply the ReLU derivative, which is 1 where \(z>0\) and 0 where \(z<0\):

\[ z^{(1)}=\begin{bmatrix} 0.2 \\ -0.8 \end{bmatrix} \;\Rightarrow\; \mathrm{ReLU}'(z^{(1)})=\begin{bmatrix} 1 \\ 0 \end{bmatrix} \] \[ \delta^{(1)}=\begin{bmatrix} -0.532 \\ 0.380 \end{bmatrix}\odot\begin{bmatrix} 1 \\ 0 \end{bmatrix} \]
\[ \boxed{ \delta^{(1)}=\begin{bmatrix} -0.532 \\ 0 \end{bmatrix} } \]

The \(0.380\) is computed and then thrown away. The second hidden neuron receives zero gradient in both directions — it neither contributed to the prediction nor learns from the error.

First-layer gradients

\[ \nabla W^{(1)}=x\,(\delta^{(1)})^{T} =\begin{bmatrix} 1 \\ -2 \end{bmatrix}\begin{bmatrix} -0.532 & 0 \end{bmatrix} \]
\[ \boxed{ \nabla W^{(1)}=\begin{bmatrix} -0.532 & 0 \\ 1.064 & 0 \end{bmatrix} } \qquad \boxed{ \nabla b^{(1)}=\begin{bmatrix} -0.532 \\ 0 \end{bmatrix} } \]

Note \(1.064\) is positive: \(x_2=-2\) flips the sign of the delta.

(d) Update every parameter

\[ \theta_{\text{new}}=\theta_{\text{old}}-\eta\nabla\theta, \qquad \eta=0.1 \]
\[ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.7+0.0152 \\ -0.5-0 \end{bmatrix} \qquad b^{(2)}_{\text{new}}=0.1+0.076 \]
\[ \boxed{ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.7152 \\ -0.5 \end{bmatrix} } \qquad \boxed{ b^{(2)}_{\text{new}}=0.176 } \]
\[ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.5+0.0532 & -0.4 \\ 0.2-0.1064 & 0.3 \end{bmatrix} \qquad b^{(1)}_{\text{new}}=\begin{bmatrix} 0.1+0.0532 \\ 0.2 \end{bmatrix} \]
\[ \boxed{ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.5532 & -0.4 \\ 0.0936 & 0.3 \end{bmatrix} } \qquad \boxed{ b^{(1)}_{\text{new}}=\begin{bmatrix} 0.1532 \\ 0.2 \end{bmatrix} } \]

Every parameter attached to the dead unit — column 2 of \(W^{(1)}\), \(b^{(1)}_2\), and \(W^{(2)}_2\) — is unchanged. Write the unchanged values out anyway; they are part of the answer.

(e) A second forward pass

Re-run the network with the updated parameters and the same input.

\[ z'^{(1)}_1 = 0.5532(1)+0.0936(-2)+0.1532 = 0.5532-0.1872+0.1532 \qquad \boxed{ z'^{(1)}_1=0.5192 } \] \[ z'^{(1)}_2 = -0.4(1)+0.3(-2)+0.2 \qquad \boxed{ z'^{(1)}_2=-0.8 } \]

The second unit is still negative, so it stays clipped:

\[ h'=\begin{bmatrix} 0.5192 \\ 0 \end{bmatrix} \]
\[ \hat y' = 0.7152(0.5192)+0.176 = 0.37133+0.176 \]
\[ \boxed{ \hat y' \approx 0.5473 } \]
\[ L'=\tfrac12(0.5473-1)^{2}=\tfrac12(-0.4527)^{2} \]
\[ \boxed{ L' \approx 0.1025 } \]

Did it learn?

Prediction \(\hat y\)Loss
Before the step\(0.24\)\(0.2888\)
After one step\(0.5473\)\(0.1025\)

The prediction moved from \(0.24\) toward the target of \(1\), and the loss fell by about \(65\%\) in a single step. That is the sanity check to state in an exam: after one gradient step the loss must not increase (for a small enough \(\eta\)). If yours goes up, you have a sign error.

Final answer sheet

\[ \boxed{ z^{(1)}=\begin{bmatrix} 0.2 \\ -0.8 \end{bmatrix} } \quad \boxed{ h=\begin{bmatrix} 0.2 \\ 0 \end{bmatrix} } \quad \boxed{ \hat y=0.24 } \quad \boxed{ L=0.2888 } \quad \boxed{ \delta^{(2)}=-0.76 } \] \[ \boxed{ \nabla W^{(2)}=\begin{bmatrix} -0.152 \\ 0 \end{bmatrix} } \quad \boxed{ \nabla b^{(2)}=-0.76 } \quad \boxed{ \delta^{(1)}=\begin{bmatrix} -0.532 \\ 0 \end{bmatrix} } \] \[ \boxed{ \nabla W^{(1)}=\begin{bmatrix} -0.532 & 0 \\ 1.064 & 0 \end{bmatrix} } \quad \boxed{ \nabla b^{(1)}=\begin{bmatrix} -0.532 \\ 0 \end{bmatrix} } \] \[ \boxed{ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.7152 \\ -0.5 \end{bmatrix} } \quad \boxed{ b^{(2)}_{\text{new}}=0.176 } \quad \boxed{ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.5532 & -0.4 \\ 0.0936 & 0.3 \end{bmatrix} } \quad \boxed{ b^{(1)}_{\text{new}}=\begin{bmatrix} 0.1532 \\ 0.2 \end{bmatrix} } \] \[ \boxed{ \hat y'\approx0.5473 } \qquad \boxed{ L'\approx0.1025 } \]

Two things to carry forward

\[ \boxed{ \text{Linear output} + \tfrac12(\hat y-y)^{2} \;\Longrightarrow\; \delta^{(2)}=\hat y-y } \]
\[ \boxed{ \text{A ReLU unit with } z<0 \text{ gets zero gradient — its weights do not move.} } \]
