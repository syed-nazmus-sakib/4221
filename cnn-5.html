Targets the two easily confused skills: computational cost (previous final) and receptive field (retake, \(r_l,j_l\) notation).

The full question

Fresh CNN Problem 2 · standard vs depthwise-separable + receptive field

An input feature map has size

\[ 56\times56\times48 \]

and the desired output has 96 channels.

DesignConfiguration
Design AStandard \(3\times3\) convolution, 96 filters, same padding, stride 1.
Design B\(3\times3\) depthwise convolution, same padding, stride 1, followed by a \(1\times1\) pointwise convolution producing 96 channels.

Every convolutional filter has one bias. For computational cost, ignore bias operations.

  • (a)Determine all output shapes for Design A and Design B.
  • (b)Calculate the trainable parameters for the standard convolution, the depthwise stage, the pointwise stage, and the total depthwise-separable block. Calculate the parameter ratio and percentage saving.
  • (c)Calculate the MACs required by the standard convolution.
  • (d)Calculate the MACs required by the depthwise and pointwise stages and their total. Compare the two designs and calculate the computational saving.
  • (e)Determine the receptive field after \(3\times3\) Conv \(\rightarrow\) \(3\times3\) Conv \(\rightarrow\) \(5\times5\) Conv, where all convolutions have stride 1.
  • (f)Repeat the receptive-field calculation when a \(2\times2\), \(s=2\) max-pooling layer is inserted between the first and second convolution.

Section map: parts (c) and (d) are answered together in Computational cost (MACs); part (e) is Receptive field — no pooling and part (f) is Insert MaxPool.

Given

\[ \boxed{56\times56\times48} \rightarrow 96\text{ output channels}. \]

Design A: \(3\times3\), 96 filters, same, s=1. Design B: DW \(3\times3\) same s=1 + PW \(1\times1\) 96 filters. Every filter has one bias. For MACs, ignore bias, count MACs.

(a) Output shapes

\[ n_{\text{out}} = \left\lfloor \frac{n+2p-k}{s} \right\rfloor+1. \quad 3\times3,\ s=1,\ \text{same }p=1: \] \[ n_{\text{out}} = \frac{56+2-3}{1}+1 = 56. \]
\[ \boxed{56\times56\times96} \]

Depthwise stage preserves 48 ch: \(\boxed{56\times56\times48}\), then pointwise → \(\boxed{56\times56\times96}\). Both designs produce \(\boxed{56\times56\times96}\). Difference is cost/params, not shape.

(b) Parameter counts

Design A — standard

\[ P_{\text{std}} =(K^2C_{in}+1)C_{out}. \quad K=3,\ C_{in}=48,\ C_{out}=96. \] \[ 3\times3\times48 = 432.+1 = 433. \quad 433\times96 = 433(100-4) = 43{,}300-1{,}732 \]
\[ \boxed{P_{\text{standard}}=41{,}568} \]

Depthwise

\[ P_{DW} =(K^2+1)C_{in}. \quad 9+1=10. \quad 10\times48 \]
\[ \boxed{P_{DW}=480} \]

Pointwise

\[ 1\times1\times48 = 48.+1 = 49. \quad 49\times96 = 49(100-4) = 4900-196 \]
\[ \boxed{P_{PW}=4{,}704} \]
\[ P_{DS} = 480+4704 \quad \boxed{P_{DS}=5{,}184} \quad \boxed{ 41{,}568\quad\text{vs}\quad5{,}184 } \]
\[ \frac{41{,}568}{5{,}184} \approx 8.02. \]
\[ \boxed{ \text{Standard uses about }8.02\times \text{ as many parameters} } \]
\[ \frac{5184}{41568}\times100 \approx 12.47\%. \]
\[ \boxed{\text{DS uses about }12.47\%} \quad \boxed{\text{Parameter saving}\approx87.53\%} \]

(c) Computational cost (MACs)

\[ \boxed{\text{Parameter count}\neq\text{computational cost}} \] Every filter applied at every output location: \(56\times56 = 3136.\)

Standard MACs

\[ MAC_{\text{std}} = H_oW_oK^2C_{in}C_{out} = 56\times56\times9\times48\times96. \] \[ 9\times48\times96 = 41{,}472. \quad 3136\times41{,}472. \]
\[ \boxed{ MAC_{\text{std}} = 130{,}056{,}192 } \quad \boxed{130.06\text{ million MACs}} \]

Depthwise MACs

\[ MAC_{DW} = 56\times56\times9\times48 = 3136\times432. \]
\[ \boxed{ MAC_{DW}=1{,}354{,}752 } \quad 1.355M. \]

Pointwise MACs

\[ MAC_{PW} = 56\times56\times48\times96 = 3136\times4608. \]
\[ \boxed{ MAC_{PW}=14{,}450{,}688 } \]
\[ MAC_{DS} = 1{,}354{,}752+14{,}450{,}688 \quad \boxed{ MAC_{DS}=15{,}805{,}440 } \quad \boxed{15.81M} \]
\[ \frac{130.056}{15.805} \approx 8.23. \]
\[ \boxed{ \text{Standard requires about }8.23\times \text{ more MACs} } \]
\[ \frac{15.805}{130.056}\times100 \approx 12.15\%. \]
\[ \boxed{12.15\%} \quad \boxed{\text{Computation saving}\approx87.85\%} \]

Parameter saving ≈87.53% vs MAC saving ≈87.85% — close but not identical (biases in params, ignored in MACs).

(d) Receptive field — no pooling

\(3\times3 \rightarrow 3\times3 \rightarrow 5\times5\), all s=1.

\[ \boxed{ r_l=r_{l-1}+(k_l-1)j_{l-1} } \qquad \boxed{ j_l=j_{l-1}s_l } \quad r_0=1,\ j_0=1. \]
\[ r_1 = 1+(3-1)(1) = 3.\ j_1=1. \quad \boxed{r_1=3} \] \[ r_2 = 3+(3-1)(1) = 5. \quad \boxed{r_2=5} \] \[ r_3 = 5+(5-1)(1) = 9. \]
\[ \boxed{\text{Final RF}=9\times9} \]

(e) Insert MaxPool + final sheet

\(3\times3 \rightarrow 2\times2\) Pool s=2 \(\rightarrow 3\times3 \rightarrow 5\times5.\)

\[ r_1 = 1+(3-1)(1)=3.\ j_1=1. \quad \boxed{r_1=3,\ j_1=1} \] \[ r_2 = 3+(2-1)(1)=4.\ j_2=2. \quad \boxed{r_2=4,\ j_2=2} \] \[ r_3 = 4+(3-1)(2)=8.\ j_3=2. \quad \boxed{r_3=8} \] \[ r_4 = 8+(5-1)(2)=16. \]
\[ \boxed{\text{Final RF}=16\times16} \]

Without pooling \(\boxed{9\times9}\); with stride-2 pooling \(\boxed{16\times16}\) — after pooling \(j=2\), each step covers 2 input pixels.

\[ \boxed{\text{Output}=56\times56\times96} \quad \boxed{P_{\text{standard}}=41{,}568} \quad \boxed{P_{DW}=480} \quad \boxed{P_{PW}=4{,}704} \quad \boxed{P_{DS}=5{,}184} \] \[ \boxed{\text{ratio}\approx8.02\times} \quad \boxed{\text{saving}\approx87.53\%} \quad \boxed{MAC_{\text{std}}=130{,}056{,}192} \quad \boxed{MAC_{DS}=15{,}805{,}440} \] \[ \boxed{3\rightarrow3\rightarrow5 \Rightarrow 9\times9} \quad \boxed{3\rightarrow Pool \rightarrow 3\rightarrow5 \Rightarrow 16\times16} \]
