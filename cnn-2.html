Standard 5×5 Conv + Depthwise + Pointwise + pooling + FC. Intermediate sizes 224→112→56 given; every filter / neuron has one bias.

Architecture

\[ 224\times224\times3 \rightarrow \text{Standard }5\times5\text{ Conv, 20 filters} \rightarrow 2\times2\text{ MaxPool} \] \[ \rightarrow 3\times3\text{ Depthwise Conv} \rightarrow 1\times1\text{ Pointwise Conv, 40 filters} \] \[ \rightarrow 2\times2\text{ MaxPool} \rightarrow \text{Flatten} \rightarrow \text{FC }100 \rightarrow \text{FC }5. \]

(a) Parameters in Conv1, Conv2-DW, Conv2-PW, FC1 and FC2, and total. (b) Replace Conv2 with one standard \(3\times3\) convolution producing 40 maps. Its parameters + reduction by DS version. (c) If Conv1 changed from same to valid padding, its output spatial size.

Q2(a) — Parameter count

Conv1

Input channels \(C_{in}=3.\) Kernel \(5\times5.\) 20 output filters.

\[ P=(5\times5\times3+1)\times20 = (75+1)\times20 = 76\times20 \]
\[ \boxed{1{,}520} \]

Conv2-DW

After Conv1 and Pool1: \(112\times112\times20.\) Depthwise = one \(3\times3\) filter per input channel. One filter \(3\times3\times1 = 9\) weights + bias \(= 10.\) 20 channels:

\[ \boxed{P_{DW}=200} \]

Conv2-PW

Input channels 20. Pointwise \(1\times1.\) Each output filter \(1\times1\times20 = 20\) weights + bias \(= 21.\) 40 output filters:

\[ P_{PW}=21\times40 \quad \boxed{P_{PW}=840} \]

Pool2 and flatten size

After pointwise: \(112\times112\times40.\) After \(2\times2\), stride-2 pooling: \(56\times56\times40.\) Flatten \(56\times56\times40 = 3136\times40\):

\[ \boxed{125{,}440}. \]

FC1

\[ P_{FC1} = 125{,}440\times100+100 = 12{,}544{,}000+100 \]
\[ \boxed{12{,}544{,}100} \]

FC2

\[ 100\rightarrow5. \quad P=100\times5+5 \quad \boxed{505} \]

Total

\[ P_{total} = 1520+200+840+12{,}544{,}100+505. \quad 1520+200+840=2560. \quad \boxed{12{,}547{,}165} \]

Q2(b) — Replace DS Conv with standard \(3\times3\) Conv

Input channels 20, output channels 40. Each standard filter covers all 20 input channels. One filter \(3\times3\times20 = 180\) weights + bias \(= 181.\) 40 filters:

\[ P_{std}=181\times40. \quad \boxed{P_{std}=7{,}240} \]

Depthwise-separable block used \(P_{DS} = 200+840 = 1{,}040.\)

How many times more?

\[ \frac{7240}{1040} \approx 6.96. \]
\[ \boxed{\text{standard uses about }6.96\times\text{ more parameters}} \]
\[ \frac{1040}{7240}\times100 \approx 14.36\%. \]
\[ \boxed{\text{DS uses only }14.36\%\text{ of the standard parameters}} \]
\[ 100-14.36 = 85.64\%. \quad \boxed{\text{Parameter reduction}\approx85.64\%} \]

Bias-free theoretical expression gives ≈13.6%, while exact with biases gives 14.36%.

Q2(c) — Same padding → valid padding

Originally \(224\times224\times3\) with \(5\times5\), stride 1. For valid \(p=0\):

\[ n_{out} = \frac{224-5}{1}+1 = 219+1 = 220. \]
\[ \boxed{220\times220} \quad \boxed{220\times220\times20}. \]
