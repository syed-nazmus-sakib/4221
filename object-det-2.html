Given

same object class · NMS IoU threshold 0.50 initially

A detector predicts four bounding boxes for the same object class:

Box\((x_1,y_1)\)\((x_2,y_2)\)Confidence
A(20, 20)(80, 80)0.92
B(32, 32)(92, 92)0.84
C(12, 12)(72, 72)0.76
D(130, 130)(180, 180)0.62

Initially use an NMS IoU threshold of 0.50.

(a) Compute \(IoU(A,B)\) and \(IoU(A,C)\), showing intersection and union areas.

(b) Apply NMS with threshold \(0.50\). Show every suppression decision and give the surviving boxes.

Suppose the ground-truth box is \[ G=(20,20,80,80). \]

(c) Using the boxes surviving part (b), classify each as TP or FP using \(IoU \ge 0.5\).

(d) Now apply a confidence threshold of 0.80 before NMS. Which boxes finally survive?

(e) Go back to all four original boxes, remove the confidence pre-filter, and increase the NMS IoU threshold from \(0.50\) to \(0.65\). What changes?

Solution (a) — IoU

intersection / union · all of A, B, C are 60×60

Remember:

\[ IoU = \frac{\text{Intersection}}{\text{Union}} \] \[ \text{Union} = A_1 + A_2 - \text{Intersection}. \]

All of A, B, and C are \(60 \times 60\), so

\[ A_A = A_B = A_C = 3600. \]

IoU(A,B)

A: \((20,20) \rightarrow (80,80)\) · B: \((32,32) \rightarrow (92,92)\)

The overlapping region starts at

\[ (\max(20,32),\max(20,32)) = (32,32) \]

and ends at

\[ (\min(80,92),\min(80,92)) = (80,80). \]

Therefore,

\[ W_I = 80-32 = 48 \] \[ H_I = 80-32 = 48 \] \[ A_I = 48 \times 48 = 2304. \]

Union:

\[ A_U = 3600 + 3600 - 2304 \] \[ = 4896. \]

Therefore,

\[ IoU(A,B) = \frac{2304}{4896} \]
\[ \boxed{IoU(A,B) \approx 0.471} \]

The important observation: \(0.471 < 0.50.\) So A and B are not sufficiently overlapping to suppress each other at threshold 0.5.

IoU(A,C)

C: \((12,12) \rightarrow (72,72)\)

The intersection of A and C is \((20,20) \rightarrow (72,72).\) Therefore,

\[ W_I = 72-20 = 52 \] \[ H_I = 72-20 = 52 \] \[ A_I = 52 \times 52 = 2704. \]

Union:

\[ A_U = 3600 + 3600 - 2704 \] \[ = 4496. \]

Hence,

\[ IoU(A,C) = \frac{2704}{4496} \]
\[ \boxed{IoU(A,C) \approx 0.601} \]

Thus, \(0.601 > 0.50.\) So C can be suppressed by A.

Solution (b) — Standard NMS, threshold = 0.50

sort → select → suppress → repeat

First sort by confidence:

\[ A(0.92) > B(0.84) > C(0.76) > D(0.62). \]

Step 1: Select A

A is the highest-confidence prediction, so we keep A. Now compare A with every remaining box.

A vs B: \(IoU(A,B) = 0.471 < 0.50\)

\[ \boxed{\text{Keep B}} \]

A vs C: \(IoU(A,C) = 0.601 > 0.50\)

\[ \boxed{\text{Suppress C}} \]

A vs D: They are far apart, so \(IoU(A,D) = 0.\)

\[ \boxed{\text{Keep D}} \]

After processing A: \(\{B, D\}\) remain.

Step 2: Select B

B now has the highest remaining confidence. B and D do not overlap: \(IoU(B,D) = 0.\) So D remains.

\[ \boxed{\text{NMS survivors}=\{A,B,D\}} \]

This is exactly the same NMS procedure used in the course solutions: sort by confidence, select the highest box, compare IoUs, suppress above threshold, then repeat.

Solution (c) — TP / FP

ground truth G = (20,20,80,80) · rule: IoU ≥ 0.5 → TP

Ground truth:

\[ G = (20,20,80,80). \]

Our surviving boxes are: \(A,\; B,\; D.\)

Use \(IoU(\text{prediction}, G) \ge 0.5\) for a true positive.

Box A

A is exactly equal to G. Therefore:

\[ IoU(A,G) = 1. \]
\[ \boxed{A = \text{TP}} \]

Box B

Because \(G = A\),

\[ IoU(B,G) = IoU(B,A) = 0.471. \]

Since \(0.471 < 0.5\),

\[ \boxed{B = \text{FP}} \]

Box D

D does not overlap G: \(IoU(D,G) = 0.\) Therefore:

\[ \boxed{D = \text{FP}} \]

Final:

\[ \boxed{A = \text{TP},\quad B = \text{FP},\quad D = \text{FP}} \]

This matches the exact TP/FP question type from the in-course paper.

Solution (d) — Confidence threshold = 0.80 before NMS

two thresholds — do not confuse them

This is where you must distinguish two thresholds.

confidence threshold = 0.80 NMS IoU threshold = 0.50

First do confidence filtering.

A: \(0.92 \ge 0.80\) — keep.   B: \(0.84 \ge 0.80\) — keep.

C: \(0.76 < 0.80\) — discard.   D: \(0.62 < 0.80\) — discard.

So before NMS we have only:

\[ \boxed{\{A,B\}} \]

Now NMS: \(IoU(A,B) = 0.471 < 0.50.\) Therefore B is not suppressed.

\[ \boxed{\{A,B\}} \]

This is the exact ordering used in the in-course question: confidence filtering first, then NMS.

Solution (e) — Increase NMS threshold to 0.65

all four boxes restored · no confidence filtering · T = 0.65

Now restore all four boxes. There is no confidence filtering.

\[ T_{NMS} = 0.65. \]

Sort: \(A > B > C > D.\) Select A.

For B: \(IoU(A,B) = 0.471 < 0.65\) — keep B.

For C: \(IoU(A,C) = 0.601 < 0.65\) — keep C.

For D: \(IoU(A,D) = 0\) — keep D.

Now B is selected next. We need B vs C.

B: \((32,32) \rightarrow (92,92)\) · C: \((12,12) \rightarrow (72,72).\)

Intersection: \((32,32) \rightarrow (72,72)\) so

\[ A_I = 40 \times 40 = 1600. \]

Union:

\[ 3600 + 3600 - 1600 = 5600. \]

Hence:

\[ IoU(B,C) = \frac{1600}{5600} \] \[ \approx 0.286. \]

Since \(0.286 < 0.65,\) C remains. D also remains.

\[ \boxed{\text{Survivors}=\{A,B,C,D\}} \]

Compare that with threshold \(0.50\):

\[ T = 0.50 \Rightarrow \{A,B,D\} \] \[ T = 0.65 \Rightarrow \{A,B,C,D\}. \]

Key intuition

\[ \boxed{\text{Higher NMS threshold} \Rightarrow \text{less suppression}} \]

A box must now overlap more strongly before it is considered a duplicate.
