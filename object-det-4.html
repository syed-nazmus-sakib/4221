Practice Problem 3 — Multi-Class NMS

The one major object-detection pattern not yet practiced independently. The retake exam asks you to compare class-agnostic NMS with multi-class NMS, where boxes from different classes are not allowed to suppress one another.

Given

T_NMS = 0.50 · 5 boxes · Car / Person
BoxClass\((x_1,y_1)\)\((x_2,y_2)\)Conf.
ACar(20, 20)(80, 80)0.93
BCar(30, 30)(90, 90)0.85
CPerson(25, 25)(75, 75)0.81
DPerson(120, 120)(180, 180)0.73
ECar(130, 130)(190, 190)0.68
\[ T_{\text{NMS}} = 0.50. \]

(a) Compute \(IoU(A,B),\; IoU(A,C),\; IoU(D,E).\)

(b) Apply class-agnostic NMS with threshold \(0.50\).

(c) Apply multi-class NMS with the same threshold. Perform NMS separately for Car and Person boxes.

(d) Which box or boxes are saved by multi-class NMS compared with class-agnostic NMS? Explain why.

(e) Suppose a confidence threshold of \(T_{\text{conf}} = 0.75\) is applied before multi-class NMS. Which boxes finally survive?

Solution (a) — Compute the IoUs

1. \(IoU(A,B)\)

A: \((20,20)\rightarrow(80,80)\) · B: \((30,30)\rightarrow(90,90)\) · Both areas \(60\times 60 = 3600.\)

Intersection: \((30,30)\rightarrow(80,80)\) so \(A_I = 50\times 50 = 2500.\)

\[ A_U = 3600+3600-2500 = 4700. \]
\[ \boxed{IoU(A,B)=\frac{2500}{4700}\approx 0.532} \]

2. \(IoU(A,C)\)

C: \((25,25)\rightarrow(75,75)\) · Area \(50\times 50 = 2500.\) C is completely inside A. Therefore intersection \(A_I = 2500.\)

\[ A_U = 3600+2500-2500 = 3600. \]
\[ \boxed{IoU(A,C)=\frac{2500}{3600}\approx 0.694} \]

Notice: \(IoU(A,C) > 0.5,\) but A is Car while C is Person. That distinction will matter later.

3. \(IoU(D,E)\)

D: \((120,120)\rightarrow(180,180)\) · E: \((130,130)\rightarrow(190,190)\) · Both areas \(3600.\)

Intersection: \((130,130)\rightarrow(180,180)\) so \(A_I = 50\times 50 = 2500.\) Union \(4700.\)

\[ \boxed{IoU(D,E)\approx 0.532} \]

Again, they overlap enough for suppression at \(0.5\), but D = Person, E = Car.

Solution (b) — Class-Agnostic NMS

Ignore the class label completely.

Sort all predictions by confidence:

\[ A(0.93) > B(0.85) > C(0.81) > D(0.73) > E(0.68) \]

Step 1 — Select A

Keep A. A vs B: \(IoU(A,B) = 0.532 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

A vs C: \(IoU(A,C) = 0.694 > 0.50\)

\[ \boxed{\text{Suppress C}} \]

Even though C is a Person, it is suppressed because class-agnostic NMS ignores labels.

A has essentially no overlap with D or E. So keep D and E. Remaining: \(D,\;E.\)

Step 2 — Select D

Compare D with E: \(IoU(D,E) = 0.532 > 0.50.\)

\[ \boxed{\text{Suppress E}} \]

Again, D is Person and E is Car, but class is ignored.

\[ \boxed{\text{Class-agnostic survivors}=\{A,D\}} \]

This is exactly the behavior illustrated in the retake solution, where a high-confidence car suppresses an overlapping person under class-agnostic NMS.

Solution (c) — Multi-Class NMS

each class independently · then combine

Now we process each class independently.

Car boxes — \(A(0.93),\; B(0.85),\; E(0.68)\)

Select A. A vs B: \(0.532 > 0.50\)

\[ \boxed{\text{Suppress B}} \]

A vs E: far apart. \(IoU(A,E) = 0.\) Therefore keep E.

\[ \boxed{\{A,E\}} \]

Person boxes — \(C(0.81),\; D(0.73)\)

They are far apart: \(IoU(C,D) = 0.\) Therefore both remain.

\[ \boxed{\{C,D\}} \]

Combining both classes:

\[ \boxed{\text{Multi-class survivors}=\{A,C,D,E\}} \]

Same procedure as the retake solution: separate detections by class, run NMS independently within each class, and combine survivors afterward.

Solution (d) — What was saved?

Compare: \(\text{Class-agnostic} = \{A,D\}\) versus \(\text{Multi-class} = \{A,C,D,E\}.\)

\[ \boxed{C\text{ and }E} \]

C

C strongly overlaps A: \(IoU(A,C) = 0.694.\) But A = Car, C = Person. Therefore A cannot suppress C under multi-class NMS.

E

E strongly overlaps D: \(IoU(D,E) = 0.532.\) But D = Person, E = Car. So D cannot suppress E either.

\[ \boxed{\text{Different classes do not suppress each other in multi-class NMS.}} \]

That is the central idea of this whole problem.

Solution (e) — Confidence threshold first

\[ T_{\text{conf}} = 0.75. \]

A: \(0.93 \ge 0.75\) — keep. B: \(0.85 \ge 0.75\) — keep. C: \(0.81 \ge 0.75\) — keep. D: \(0.73 < 0.75\) — discard. E: \(0.68 < 0.75\) — discard.

\[ \boxed{\{A,B,C\}} \]

Now perform multi-class NMS.

Cars — \(A,B\)

\(IoU(A,B) = 0.532 > 0.50\) so A suppresses B. Car survivor: \(A\)

Persons — only C

Only C remains. Therefore C automatically survives.

\[ \boxed{\{A,C\}} \]

The entire NMS family in one picture

\(\boxed{\text{Confidence filter}}\) removes predictions with low confidence.

\(\boxed{\text{Class-agnostic NMS}}\) removes highly overlapping boxes regardless of class.

\(\boxed{\text{Multi-class NMS}}\) removes highly overlapping boxes only within the same class.
