Full question

Previous-year final · IoU and NMS

An object detector predicts the following four bounding boxes for the same class. Coordinates use the format \((x_1,y_1,x_2,y_2)\).

BoxTop-left \((x_1,y_1)\)Bottom-right \((x_2,y_2)\)Confidence
A(30, 30)(90, 90)0.88
B(40, 40)(100, 100)0.80
C(35, 35)(85, 85)0.72
D(150, 150)(200, 200)0.60
  1. Calculate \(IoU(A,B)\).
  2. Calculate \(IoU(A,C)\).
  3. Calculate \(IoU(A,D)\).
  4. Apply non-maximum suppression (NMS) with IoU threshold \(0.50\). List the boxes that remain.
  5. Repeat NMS with threshold \(0.60\). State what changes and why.

NMS rule: sort boxes by decreasing confidence, keep the highest-confidence remaining box, and suppress a lower-confidence box when its IoU with the kept box is greater than the threshold.

Formula

\[w_I=\max(0,\min(x_2^A,x_2^B)-\max(x_1^A,x_1^B))\]\[h_I=\max(0,\min(y_2^A,y_2^B)-\max(y_1^A,y_1^B))\]\[IoU=\frac{A_I}{A_A+A_B-A_I}\]

Complete solution

1. \(IoU(A,B)\)

Both boxes have area \(60\times60=3600\). Their intersection runs from \((40,40)\) to \((90,90)\), so it is \(50\times50=2500\).

\[A_U=3600+3600-2500=4700\]\[IoU(A,B)=\frac{{2500}}{{4700}}\approx0.532\]
\[\boxed{{IoU(A,B)\approx0.532}}\]

2. \(IoU(A,C)\)

C is completely inside A. Thus the intersection is the whole area of C: \(50\times50=2500\). The union is the area of A: \(3600\).

\[\boxed{{IoU(A,C)=\frac{{2500}}{{3600}}\approx0.694}}\]

3. \(IoU(A,D)\)

A and D do not overlap, so their intersection area is zero.

\[\boxed{{IoU(A,D)=0}}\]

4. NMS with threshold \(0.50\)

Confidence order: \(A(0.88)>B(0.80)>C(0.72)>D(0.60)\). Keep A. Since \(0.532>0.50\), suppress B. Since \(0.694>0.50\), suppress C. D has no overlap with A, so keep D.

\[\boxed{{\text{{Survivors}}=\{{A,D\}}}}\]

5. NMS with threshold \(0.60\)

Keep A. Now \(IoU(A,B)=0.532<0.60\), so B stays. But \(IoU(A,C)=0.694>0.60\), so C is suppressed. D stays because it does not overlap.

\[\boxed{{\text{{Survivors}}=\{{A,B,D\}}}}\]

A higher NMS threshold demands more overlap before suppression, so it usually allows more boxes to survive.
