The full question

Fresh CNN Problem 1 · full architecture + depthwise-separable convolution

Consider the network

\[ 96\times96\times3 \] \[ \rightarrow \text{Conv1: 24 filters, }5\times5,\ p=2,\ s=2 \] \[ \rightarrow \text{Pool1: }3\times3,\text{ valid},\ s=2 \] \[ \rightarrow \text{Conv2-DW: }3\times3,\text{ same},\ s=1 \] \[ \rightarrow \text{Conv2-PW: 48 filters, }1\times1 \] \[ \rightarrow \text{Conv3: 96 filters, }3\times3,\text{ valid},\ s=2 \] \[ \rightarrow \text{Flatten} \rightarrow FC(50) \rightarrow FC(6). \]

Assume every filter and FC neuron has one bias.

  • (a)Determine the output shape after every layer and the flatten size.
  • (b)Calculate the number of trainable parameters in every trainable layer and the total.
  • (c)Replace Conv2-DW + Conv2-PW with a standard \(3\times3\) convolution producing 48 channels. Calculate its parameters.
  • (d)Compare the parameter counts of the standard and depthwise-separable Conv2 blocks, and calculate the reduction ratio / percentage saving.

(a) Output shapes

Input

\[ \boxed{96\times96\times3} \]

Conv1 — n=96, k=5, p=2, s=2

\[ n_{out} = \left\lfloor \frac{96+4-5}{2} \right\rfloor+1 = \left\lfloor \frac{95}{2} \right\rfloor+1 = 47+1 = 48. \]
\[ \boxed{Conv1=48\times48\times24} \]

Stride 2 approximately halves spatial dims.

Pool1 — k=3, p=0, s=2

\[ n_{out} = \left\lfloor \frac{48-3}{2} \right\rfloor+1 = \left\lfloor \frac{45}{2} \right\rfloor+1 = 22+1 = 23. \]
\[ \boxed{Pool1=23\times23\times24} \]

Odd 23 is intentional — don't assume pooling always halves exactly.

Conv2-DW — same, s=1

\[ \boxed{Conv2\text{-}DW=23\times23\times24} \]

Conv2-PW — 48 filters

\[ \boxed{Conv2\text{-}PW=23\times23\times48} \]
Main role of pointwise: \[ \boxed{\text{mix/change channels}} \] while depthwise handles spatial filtering per channel.

(b) Parameter counts

Conv1

\(5\times5\times3 = 75\) + bias \(= 76.\) 24 filters:

\[ P_{Conv1} = 76\times24. \quad \boxed{P_{Conv1}=1{,}824} \]

Conv2-DW

One \(3\times3\) per channel: \(9+1 = 10.\) ×24:

\[ P_{DW} = 10\times24 \quad \boxed{P_{DW}=240} \]

Conv2-PW

Each \(1\times1\times24 = 24\) + bias \(= 25.\) ×48:

\[ P_{PW} = 25\times48 \quad \boxed{P_{PW}=1{,}200} \]
\[ P_{DS} = 240+1200 \quad \boxed{P_{DS}=1{,}440} \]

Conv3

One filter \(3\times3\times48 = 432\) + bias \(= 433.\) ×96: \(433\times(100-4) = 43{,}300-1{,}732\):

\[ \boxed{P_{Conv3}=41{,}568} \]

(c) Replace Conv2 with standard convolution

\(C_{in}=24,\; C_{out}=48.\) Each filter \(3\times3\times24 = 216\) + bias \(= 217.\) ×48: \(217\times(50-2) = 10{,}850-434\):

\[ \boxed{ P_{standard}=10{,}416 } \qquad \boxed{ P_{DS}=1{,}440 } \]

(d) Parameter reduction + traps

\[ \frac{10{,}416}{1{,}440} \approx 7.23. \]
\[ \boxed{ \text{standard uses about }7.23\times \text{ more parameters} } \]
\[ \frac{1440}{10{,}416}\times100 \approx 13.82\%. \]
\[ \boxed{ \text{DS uses only about }13.82\% } \]
\[ 100-13.82 = 86.18\%. \quad \boxed{ \text{parameter saving}\approx86.18\% } \]

Four deliberate traps

Trap 1: \(48 \xrightarrow{\text{pool }3\times3,s=2} 23\) not 24 — use the formula.
Trap 2: DW preserves 24 ch (\(23\times23\times24\)); PW changes \(24\rightarrow48\).
Trap 3: Conv3 uses \(C_{in}=48\) from pointwise output.
Trap 4: Flatten \(11\times11\times96 = 11{,}616\) before FC.
