ANN-5

Regression Problem 1 — All-Linear Network

The simplest possible backprop: \(2\rightarrow2\rightarrow1\) with no activation anywhere, squared-error loss written without a \(\tfrac12\). That last detail is the whole point — it makes \(\delta^{(2)}=2(\hat y-y)\) rather than \(\hat y-y\).

The full question

Fresh regression practice · Problem 1 · 2 → 2 → 1 · no activations

Consider a network \(2\rightarrow2\rightarrow1\) with no activation function in either layer. Given:

\[ x=\begin{bmatrix} 1 \\ 2 \end{bmatrix}, \qquad y=1.5 \] \[ W^{(1)}=\begin{bmatrix} 0.5 & -0.3 \\ 0.2 & 0.4 \end{bmatrix}, \qquad b^{(1)}=\begin{bmatrix} 0.1 \\ -0.2 \end{bmatrix} \] \[ W^{(2)}=\begin{bmatrix} 0.6 \\ -0.5 \end{bmatrix}, \qquad b^{(2)}=0.2, \qquad \eta=0.1 \]

Use \( z^{(1)}=(W^{(1)})^{T}x+b^{(1)} \) and, because the hidden layer is linear, \( h=z^{(1)} \). The output is \( \hat y=(W^{(2)})^{T}h+b^{(2)} \). The loss is

\[ \boxed{ L=(\hat y-y)^{2} } \]

Compute:

  • (a)\(z^{(1)}\) and \(h\)
  • (b)\(\hat y\)
  • (c)\(L\)
  • (d)\(\delta^{(2)}=\partial L/\partial\hat y\)
  • (e)Gradients of \(W^{(2)},b^{(2)}\)
  • (f)The hidden-layer delta
  • (g)Gradients of \(W^{(1)},b^{(1)}\)
  • (h)The updated parameters

The network at a glance

Before solving: a linear net is one affine map

Worth noticing before any arithmetic. Substituting the hidden layer into the output:

\[ \hat y=(W^{(2)})^{T}\big((W^{(1)})^{T}x+b^{(1)}\big)+b^{(2)} = \underbrace{(W^{(2)})^{T}(W^{(1)})^{T}}_{\text{one } 1\times2 \text{ row}}x + \text{const} \]

So this two-layer network computes exactly what a single linear unit could. Stacking linear layers buys no extra expressive power — that is the whole reason activation functions exist. It is still a perfectly good backprop exercise, and it is the cleanest possible place to see the chain rule, because nothing is hidden behind an activation derivative.

   x (2)              h (2)             y^ (1)
  ┌─────┐  W(1)ᵀ     ┌────────┐  W(2)ᵀ  ┌────────┐
  │  1  │ ─────────► │ linear │ ──────► │ linear │ ──► y^ ──► (y^ − y)²  ──► L
  │  2  │  + b(1)    │ linear │  + b(2) └────────┘        y = 1.5
  └─────┘            └────────┘
       2×2                   2×1        no activation anywhere

Because \(h=z^{(1)}\), the hidden "activation derivative" is \(1\) — so in part (f) there is simply nothing to multiply by.

(a) Hidden layer

\[ (W^{(1)})^{T}=\begin{bmatrix} 0.5 & 0.2 \\ -0.3 & 0.4 \end{bmatrix} \] \[ z^{(1)}=\begin{bmatrix} 0.5 & 0.2 \\ -0.3 & 0.4 \end{bmatrix}\begin{bmatrix} 1 \\ 2 \end{bmatrix} +\begin{bmatrix} 0.1 \\ -0.2 \end{bmatrix} \]

First neuron

\[ 0.5(1)+0.2(2)+0.1 = 0.5+0.4+0.1 \qquad \boxed{ z^{(1)}_1 = 1.0 } \]

Second neuron

\[ -0.3(1)+0.4(2)-0.2 = -0.3+0.8-0.2 \qquad \boxed{ z^{(1)}_2 = 0.3 } \]

The layer is linear, so the activation is the identity and \(h=z^{(1)}\):

\[ \boxed{ h=z^{(1)}=\begin{bmatrix} 1.0 \\ 0.3 \end{bmatrix} } \]

(b) Output

\[ \hat y=(W^{(2)})^{T}h+b^{(2)} = 0.6(1.0)-0.5(0.3)+0.2 \] \[ = 0.6-0.15+0.2 \]
\[ \boxed{ \hat y = 0.65 } \]

The target is \(1.5\), so the network is currently under-predicting by \(0.85\). Expect every gradient below to push the prediction up.

(c) Loss

\[ L=(\hat y-y)^{2}=(0.65-1.5)^{2}=(-0.85)^{2} \]
\[ \boxed{ L = 0.7225 } \]

(d) Output delta

The loss is written without a \(\tfrac12\), so differentiating brings the 2 down and nothing cancels it:

\[ L=(\hat y-y)^{2} \qquad\Longrightarrow\qquad \frac{\partial L}{\partial\hat y}=2(\hat y-y) \]

The output layer is linear, so \(\partial\hat y/\partial z^{(2)}=1\) and the delta is just this derivative:

\[ \delta^{(2)}=2(0.65-1.5)=2(-0.85) \]
\[ \boxed{ \delta^{(2)} = -1.7 } \]
\[ \boxed{ \text{Linear output} + (\hat y-y)^{2} \;\Rightarrow\; \delta^{(2)}=2(\hat y-y) } \]

The sign is negative because \(\hat yraise the weights and hence the prediction — exactly what we want.

(e) Gradients of the output layer

\[ \boxed{ \frac{\partial L}{\partial W^{(2)}}=h\,\delta^{(2)} } = \begin{bmatrix} 1.0 \\ 0.3 \end{bmatrix}(-1.7) \]
\[ \boxed{ \nabla W^{(2)}=\begin{bmatrix} -1.7 \\ -0.51 \end{bmatrix} } \qquad \boxed{ \nabla b^{(2)}=\delta^{(2)}=-1.7 } \]

With a single output neuron, \(\delta^{(2)}\) is a scalar, so the "outer product" is just a scaled copy of \(h\).

(f) Hidden-layer delta

Normally this step is \(\delta^{(1)}=\big(W^{(2)}\delta^{(2)}\big)\odot g'(z^{(1)})\). Here the hidden layer is linear, so \(g'(z)=1\) and there is no activation derivative to apply:

\[ \delta^{(1)}=W^{(2)}\delta^{(2)}=\begin{bmatrix} 0.6 \\ -0.5 \end{bmatrix}(-1.7) \]
\[ \boxed{ \delta^{(1)}=\begin{bmatrix} -1.02 \\ 0.85 \end{bmatrix} } \]

Note the second entry flips sign: its weight \(-0.5\) is negative, so raising that hidden unit would lower the prediction.

(g) Gradients of the first layer

\[ \boxed{ \nabla W^{(1)}=x\,(\delta^{(1)})^{T} } = \begin{bmatrix} 1 \\ 2 \end{bmatrix}\begin{bmatrix} -1.02 & 0.85 \end{bmatrix} \]
\[ \text{Row 1: } 1(-1.02)=-1.02,\qquad 1(0.85)=0.85 \] \[ \text{Row 2: } 2(-1.02)=-2.04,\qquad 2(0.85)=1.70 \]
\[ \boxed{ \nabla W^{(1)}=\begin{bmatrix} -1.02 & 0.85 \\ -2.04 & 1.70 \end{bmatrix} } \qquad \boxed{ \nabla b^{(1)}=\delta^{(1)}=\begin{bmatrix} -1.02 \\ 0.85 \end{bmatrix} } \]

Row 2 is exactly twice row 1, because \(x_2=2x_1\). A useful check whenever the input has a simple ratio.

(h) Updated parameters

\[ \boxed{ \theta_{\text{new}}=\theta_{\text{old}}-\eta\nabla\theta },\qquad \eta=0.1 \]

Output layer

\[ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.6 \\ -0.5 \end{bmatrix}-0.1\begin{bmatrix} -1.7 \\ -0.51 \end{bmatrix} =\begin{bmatrix} 0.6+0.17 \\ -0.5+0.051 \end{bmatrix} \]
\[ \boxed{ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.77 \\ -0.449 \end{bmatrix} } \qquad b^{(2)}_{\text{new}}=0.2-0.1(-1.7) \quad \boxed{ b^{(2)}_{\text{new}}=0.37 } \]

Hidden layer

\[ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.5+0.102 & -0.3-0.085 \\ 0.2+0.204 & 0.4-0.170 \end{bmatrix} \]
\[ \boxed{ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.602 & -0.385 \\ 0.404 & 0.230 \end{bmatrix} } \qquad \boxed{ b^{(1)}_{\text{new}}=\begin{bmatrix} 0.202 \\ -0.285 \end{bmatrix} } \]

Final answer sheet

\[ \boxed{ h=z^{(1)}=\begin{bmatrix} 1.0 \\ 0.3 \end{bmatrix} } \qquad \boxed{ \hat y=0.65 } \qquad \boxed{ L=0.7225 } \qquad \boxed{ \delta^{(2)}=-1.7 } \] \[ \boxed{ \nabla W^{(2)}=\begin{bmatrix} -1.7 \\ -0.51 \end{bmatrix} } \qquad \boxed{ \nabla b^{(2)}=-1.7 } \qquad \boxed{ \delta^{(1)}=\begin{bmatrix} -1.02 \\ 0.85 \end{bmatrix} } \] \[ \boxed{ \nabla W^{(1)}=\begin{bmatrix} -1.02 & 0.85 \\ -2.04 & 1.70 \end{bmatrix} } \qquad \boxed{ \nabla b^{(1)}=\begin{bmatrix} -1.02 \\ 0.85 \end{bmatrix} } \] \[ \boxed{ W^{(2)}_{\text{new}}=\begin{bmatrix} 0.77 \\ -0.449 \end{bmatrix} } \quad \boxed{ b^{(2)}_{\text{new}}=0.37 } \quad \boxed{ W^{(1)}_{\text{new}}=\begin{bmatrix} 0.602 & -0.385 \\ 0.404 & 0.230 \end{bmatrix} } \quad \boxed{ b^{(1)}_{\text{new}}=\begin{bmatrix} 0.202 \\ -0.285 \end{bmatrix} } \]

Pattern to remember

\[ \boxed{ \text{Linear output} + L=(\hat y-y)^{2} \;\Longrightarrow\; \delta^{(2)}=2(\hat y-y) } \]

There is no output activation derivative, and with a linear hidden layer there is no hidden activation derivative either. Every other regression problem in this set adds exactly one of those factors back.
